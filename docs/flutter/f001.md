## 2.安装Flutter

总体是三步：

- 下载安装 Flutter SDK，（里面包含了 Dart SDK）
- 配置 Flutter 环境变量
- 验证 Flutter 安装


### 2.1 下载安装 Flutter SDK

下载对应`Stable channel`版本的 Flutter SDK 并解压到指定目录。
- 目录需要是纯英文目录，不要有空格。
- 注意SDK文件比较大，几GB左右，预留足够的磁盘空间。

例如，下载 Flutter SDK 到 `~/flutter_sdk/` 目录。
```sh
$ mkdir ~/flutter_sdk; cd ~/flutter_sdk

# 将下载好的 Flutter SDK 解压到 ~/flutter_sdk/ 目录中
```


### 2.2 配置环境变量

使用命令的方式：
```sh
cd ~/flutter_sdk

# 配置 Flutter 环境变量 （或者直接在 ~/.zshrc 中添加即可）
export PATH="$PWD/bin:$PATH"

# 使环境变量生效
source ~/.zshrc

# 验证 Flutter 安装
flutter doctor


# 验证 Flutter 安装，输出详细内容
flutter doctor -v
```

如果是**手动添加环境变量**（**推荐**），需要在 `~/.zshrc` 文件中添加如下内容：
```sh
# Flutter SDK 配置
export FLUTTER_ROOT="$HOME/flutter_sdk"
export PATH="$FLUTTER_ROOT/bin:$PATH"

# 可选：如果你在中国，建议配置镜像以加速下载
export PUB_HOSTED_URL=https://pub.flutter-io.cn
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn

# 可选：配置 Android SDK（如果你有 Android 开发需求）
# export ANDROID_HOME="$HOME/Library/Android/sdk"
# export PATH="$ANDROID_HOME/tools:$ANDROID_HOME/platform-tools:$PATH"


# 重新加载 zshrc 文件  或者完全重启终端
source ~/.zshrc
```


验证安装：

```sh
# ⚠️在第一次执行 flutter 命令之前，最好终端开启科学上网，它可能会下载一些依赖。

# 检查 Flutter 命令是否可用
flutter --version

# 验证 Flutter 安装
flutter doctor
```

### 5.1 版本兼容性

`Flutter`与`Android Studio`版本： `Flutter`通常支持最新稳定版`Android Studio`，但若遇到兼容问题，可：

- 更新Flutter：`flutter upgrade`。
- [降级Android Studio至官方推荐版本](https://docs.flutter.dev/tools/android-studio)。



## 6.创建第一个 Flutter 项目

在 VS Code 里：

- 1.⌘⇧P → 输入 `Flutter: New Project` → 回车
- 2.选 Application（最常用的类型）
- 3.选一个父目录（比如 ~/Developer/flutter）
- 4.项目名用全小写加下划线，比如 my_first_demo（Dart 包命名规范，不能用驼峰）
- 5.等几秒，VS Code 会自动打开新项目


**运行起来：**

- 先启动 iOS 模拟器：终端执行 `open -a Simulator`，或者在 VS Code 里 `⌘⇧P` → `Flutter: Launch Emulator`
- 确认右下角状态栏的设备是 `iPhone` 模拟器
- 按 F5（带调试运行）或 `⌘F5`（不带调试运行）
- 第一次编译会慢一点（要下 pod 依赖、构建），之后会快很多



## 7.和iOS对比

理解几个最核心的概念，建立 iOS 的简单映射关系

| #  | **Flutter**                 | **iOS 对应**                                    |
|----|----------------------------|-------------------------------------------|
| 1  | `Widget`                     | `UIView` / SwiftUI `View`                     |
| 2  | `StatelessWidget`            | SwiftUI `View`（无 `@State`）                    |
| 3  | `StatefulWidget`             | SwiftUI `View` + `@State`                     |
| 4  | `BuildContext`               | 类似 SwiftUI 的 `Environment` 链                |
| 5  | `MaterialApp` / `CupertinoApp` | `UIApplication` + 全局主题                      |
| 6  | `Scaffold`                   | `UIViewController` 的标准骨架（带导航栏+内容区+底部 tab）   |
| 7  | `Navigator.push/pop`         | `UINavigationController.pushViewController` |
| 8  | `pubspec.yaml`               | `Podfile` + `Package.swift` 合体                |
| 9  | `Hot reload`                 | Xcode Previews（但作用在整个 running app 上）      |
| 10 | `setState(() {...})`         | SwiftUI 修改 `@State` 触发 re-render            |
