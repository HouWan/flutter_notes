## 2.安装Flutter

总体是三步：

- 下载安装 Flutter SDK，（里面包含了 Dart SDK）
- 配置 Flutter 环境变量
- 验证 Flutter 安装


### 2.1 下载安装 Flutter SDK

下载对应`Stable channel`版本的 Flutter SDK 并解压到指定目录。
- 目录需要是纯英文目录，不要有空格。
- 注意SDK文件比较大，几GB左右，预留足够的磁盘空间。

例如，下载 Flutter SDK 到 `~/flutter_sdk/` 目录。
```sh
$ mkdir ~/flutter_sdk; cd ~/flutter_sdk

# 将下载好的 Flutter SDK 解压到 ~/flutter_sdk/ 目录中
```


### 2.2 配置环境变量

使用命令的方式：
```sh
cd ~/flutter_sdk

# 配置 Flutter 环境变量 （或者直接在 ~/.zshrc 中添加即可）
export PATH="$PWD/bin:$PATH"

# 使环境变量生效
source ~/.zshrc

# 验证 Flutter 安装
flutter doctor
```

如果是**手动添加环境变量**（**推荐**），需要在 `~/.zshrc` 文件中添加如下内容：
```sh
# Flutter SDK 配置
export FLUTTER_ROOT="$HOME/flutter_sdk"
export PATH="$FLUTTER_ROOT/bin:$PATH"

# 可选：如果你在中国，建议配置镜像以加速下载
export PUB_HOSTED_URL=https://pub.flutter-io.cn
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn

# 可选：配置 Android SDK（如果你有 Android 开发需求）
# export ANDROID_HOME="$HOME/Library/Android/sdk"
# export PATH="$ANDROID_HOME/tools:$ANDROID_HOME/platform-tools:$PATH"


# 重新加载 zshrc 文件  或者完全重启终端
source ~/.zshrc
```


验证安装：

```sh
# ⚠️在第一次执行 flutter 命令之前，最好终端开启科学上网，它可能会下载一些依赖。

# 检查 Flutter 命令是否可用
flutter --version

# 验证 Flutter 安装
flutter doctor
```

## 3.VS Code
- 1.在`VC Code`中安装 [`Flutter` 插件](https://marketplace.visualstudio.com/items?itemName=Dart-Code.flutter)
- 2.推荐安装[`Flutter Widget Snippets`插件](https://marketplace.visualstudio.com/items?itemName=alexisvt.flutter-snippets)，提供了很多代码片段。
- 3.上面安装Flutter SDK并配置好环境之后，重启一下`VC Code`
- 4.在 VS Code 中，点击 `View` -> `Command Palette`，输入`doctor`查看是否能正确输出。

- 更新Flutter：`flutter upgrade`。
