
## 1.括号指示器

VS Code 现在已经原生支持了非常好看的括号着色和对齐线.请按 `Cmd +` , 打开设置，搜索并确保开启以下两项：

- `Editor: Bracket Pair Colorization` -> 勾选 `True`（它会让配对的括号显示相同的颜色，一眼就能看出谁和谁是一对）。
- `Editor: Guides: Bracket Pairs` -> 设置为 `active` 或 `true`（它会在左侧画出一条垂直的彩色连线，直观地连接起始括号和结束括号）。


## 2.自动格式化
Flutter 官方的 Dart 插件其实非常聪明。只要你给的代码符合基本的格式，在你保存文件（`Cmd + S`）的那一瞬，它能自动帮你补全绝大多数的分号，并把错乱的括号重新对齐！

打开你的 VS Code `settings.json`（在命令面板 `Cmd + Shift + P` 中输入 `Preferences: Open User Settings (JSON)`），加入以下配置：

```json
{
    "editor.fontSize": 16,
    "editor.fontLigatures": false,
    "workbench.preferredHighContrastColorTheme": "Dark Modern",
    "workbench.preferredHighContrastLightColorTheme": "Dark Modern",
    "workbench.iconTheme": "vscode-icons",
    "markdown-preview-enhanced.enablePreviewZenMode": true,
    "markdown-preview-enhanced.previewTheme": "github-dark.css",
    "[dart]": {  // 这里会在安装 Flutter 插件之后，自动加上的
        "editor.formatOnSave": true,
        "editor.formatOnType": true,
        "editor.rulers": [
            80
        ],
        "editor.selectionHighlight": false,
        "editor.tabCompletion": "onlySnippets",
        "editor.wordBasedSuggestions": "off"
    },
    "editor.tabSize": 2,
    "editor.bracketPairColorization.independentColorPoolPerBracketType": true,
    "editor.guides.bracketPairs": "active",
    // Flutter UI Guides功能，开启后, 会直接在你的代码编辑器里，用彩虹虚线把每一个 Widget 的开头和闭合括号连接起来
    // 并且在末尾直接写明这是哪个 Widget 的结束括号
    "dart.previewFlutterUiGuides": true,
    // 保存时自动修复简单错误（比如自动补齐缺失的 const、引入等，有时也能顺便带上分号）
    "editor.codeActionsOnSave": {
      "source.fixAll": "explicit"
  }
}
```

> 注意⚠️： 不要把注释贴进去，注意 JSON 语法

## 3.技巧

### 3.1 善用 `Cmd + .` (Refactor 快捷键)

把光标移到你想包裹的 `Widget`（比如 `Text`）上。
- 按下 `Cmd + .`（ `Cmd` 和 `.` 键同时按下 ，或者点击左侧的小黄灯泡）。
- 选择 `Wrap with Column`、`Wrap with Container` 或 `Wrap with Row`.
- 或者选择 `fix`.

> 编辑器会自动帮你把前后的 (、)、[、] 以及逗号全部精准补全，如果想删除这一层，同样按 Cmd + . 选择 Remove this widget，它会自动完美剥离，绝不会多删或少删一个括号。
