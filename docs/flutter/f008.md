## 1.Stack/Positioned

`Stack` 是一个继承自 `MultiChildRenderObjectWidget` 的布局控件。`Stack`核心职责是：将多个子组件按堆叠(Z轴)的方式进行布局，并能控制子组件的相对定位(`Positioned`)和叠放顺序。

> `Positioned`继承自 `SingleChildRenderObjectWidget`，职责是：将子组件定位在 `Stack` 中的指定位置。


| 属性名               | 类型                  | 默认值    | 说明 |
| :---------------- | :------------------ | :------------------------------ | :--------------------------------------------- |
| **alignment**     | `AlignmentGeometry` | `.topStart` | 非 `Positioned` 子组件的对齐方式（相对于 Stack 区域）。  |
| **textDirection** | `TextDirection?`    | `null`  | 用于解析 `AlignmentDirectional` 中的方向（如 LTR / RTL）。 |
| **fit**           | `StackFit`          | `.loose`  | 控制非 `Positioned` 子组件的布局约束方式。 |
| **clipBehavior**  | `Clip`              | `.hardEdge` | 超出 Stack 边界时的裁剪行为。|
| **children**      | `List<Widget>`      | —  | 子组件列表，支持同时存在 `Positioned` 与普通 Widget。  |


**Positioned 额外属性（Stack 中定位子节点用）**

| 属性 | 类型 | 默认值 | 描述 | 源码级影响 |
|------|------|--------|------|-----------|
| **left** | `double` | `null` | 距左边界的距离 | 影响 `RenderStack._layoutPositionedChild` 的 `_getPosition` 计算 |
| **top** | `double` | `null` | 距顶边界的距离 | 同上，垂直方向定位 |
| **right** | `double` | `null` | 距右边界的距离 | 需要与 left 或 width 配合使用 |
| **bottom** | `double` | `null` | 距底边界的距离 | 需要与 top 或 height 配合使用 |
| **width** | `double` | `null` | 子Widget宽度 | 影响约束条件计算 |
| **height** | `double` | `null` | 子Widget高度 | 影响约束条件计算 |


**Stack 相关枚举与类说明：**

| 枚举 / 类                  | 作用                      | 常用值   |
| :---------------------- | :---------------------- | :------------------------------------- |
| **`StackFit`**          | 控制非 Positioned 子组件的布局大小 | - `loose`: 允许子组件按自身大小布局<br>- `expand`: 子组件尽可能扩展至父容器大小<br>- `passthrough`: 将父约束直接传递给子组件 |
| **`AlignmentGeometry`** | 控制非 Positioned 子组件的对齐方式 | - `Alignment.topLeft`<br>- `Alignment.center`<br>- `Alignment.bottomRight` 等  |
| **`Positioned`**        | Stack 专属定位子组件类  | 可设置 `left`, `right`, `top`, `bottom`, `width`, `height` |


**`StackFit` 不同模式对比：**

| 模式              | 行为描述              | 适用场景        |
| :-------------- | :---------------- | :---------- |
| **loose**       | 子组件按自身大小布局        | 一般默认选择      |
| **expand**      | 子组件强制扩展至 Stack 尺寸 | 填充型背景、遮罩层   |
| **passthrough** | 传递父约束，适用于特殊布局场景   | 特殊自定义容器内部布局 |


`Stack` 与 `Positioned` 的关系：
- ✅ 若子组件不使用 `Positioned`，则遵循 `Stack` 的 `alignment` 对齐规则；
- ✅ 若子组件被 `Positioned` 包裹，则完全由其位置参数决定位置。
- ✅ `Positioned`必须作为 `Stack` 的直接子组件。
- ✅ `Positioned`如果同时设置了`left`和`right`，则`width`会被忽略。同理，若同时设置了`top`和`bottom`，则`height`会被忽略。





**代码示例**

```dart
// 基本使用
Stack(
  alignment: Alignment.center,
  children: [
    Container(color: Colors.red, width: 300, height: 300),
    Container(color: Colors.blue, width: 200, height: 200),
    Container(color: Colors.green, width: 100, height: 100),
  ],
);


// 定位子组件示例
Stack(
  children: [
    Container(color: Colors.white, width: 200, height: 200),
    Positioned(
      // 放置到左上角，并距离左边 20 像素，距离顶部 20 像素
      left: 20,
      top: 20,
      child: Container(color: Colors.red, width: 80, height: 80),
    ),
    Positioned(
      // 放置到右下角，并距离右边 20 像素，距离底部 20 像素
      right: 20,
      bottom: 20,
      child: Container(color: Colors.red, width: 80, height: 80),
    ),
    Positioned( // 放置到中间区域，并距离左边 20 像素，距离顶部 20 像素，距离右边 20 像素，距离底部 20 像素
      right: 20,
      bottom: 20,
      top: 20,
      left: 20,
      child: Container(
        color: Colors.red.withAlpha(60),
        width: 80,
        height: 80,
      ),
    ),
  ],
)
```


## 2.Text

### 2.1 基本属性

`Text` 本身是 `StatelessWidget`，核心行为都在 `Text` → `RichText` → `TextPainter` → `Paragraph` → `Skia` 的 `pipeline` 完成。控制呈现的关键并非 `Text` 本身，而是其内部的 `TextStyle`、`StrutStyle` 与 `TextPainter`。

| 属性                     | 类型          | 说明     | 底层机制（原理级）  | 常见误区 & 最佳实践  |
| --------------- | ------------ | ------------------ | ---------------- | -------------- |
| **data**               | `String?`  | 要显示的文本内容  | 若提供 `data` 则内部构建 `TextSpan(text: data)`  | data 与 `textSpan` 不能同时存在    |
| **textSpan**           | `InlineSpan?` | 富文本内容  | 若提供，则 `Text` → `RichText` → `InlineSpan` → `TextPainter` | 富文本请尽量用 `Text.rich`    |
| **style**              | `TextStyle?`   | 字体样式：颜色、大小、粗细等 | 最终由 `ParagraphBuilder` 合并样式  | 穿透原则：`TextStyle` 会和 `DefaultTextStyle` merge |
| **strutStyle**         | `StrutStyle?`  | 修正行高的“基线撑起规则” | 作用于 TextPainter 的 layout 行高度计算  | Android/Web 有差异，建议统一设置    |
| **textAlign**          | `TextAlign`    | 左对齐/右对齐/居中等 | 作用于 Paragraph 的 alignment | 放在 Row 中常被约束，注意父布局限制  |
| **textDirection**      | `TextDirection` | ltr / rtl | RichText 构建必须有 direction，否则 assertion  |  通常无需设置  |
| **softWrap**           | `bool?`   | 是否自动换行  | 控制 Paragraph 的 line breaking    | 在 `overflow: clip` 时会影响裁剪行为  |
| **overflow**           | `TextOverflow`  | 裁剪方式：clip/ellipsis/fade  | TextPainter 在 layout 后决定渲染策略  | fade 在 Web 平台表现不一致  |
| **maxLines**           | `int?`| 最大行数 | TextPainter 在 layout 阶段依据此参数截断文本 | 设置 ellipsis 时必须搭配 maxLines  |
| **minLines**           | `int?`  | 最小行数 | 在 BoxConstraints 的 support 下撑开高度  | 不常用，但可修复高度波动问题   |
| **textScaleFactor**    | `double?` | 文本缩放比例（系统字体缩放） | 影响最终 fontSize = style.fontSize × scale   | UI 强视觉时建议 lock = 1.0 |
| **locale**             | `Locale?` | 文本的语言环境  | Paragraph layout 时用于选择字体/字形   | 多语言场景很关键 |
| **selectionColor**     | `Color?`   | 文本被选中时颜色（一般用于 SelectableText） | 只对特殊 Text Widget 生效   | 普通 Text 不支持选中 |
| **textWidthBasis**     | `TextWidthBasis`  | 决定宽度是按“最大宽度”或“第一行宽度”  | 仅在 Paragraph width 测量阶段生效  | 默认 longestLine 即可  |
| **textHeightBehavior** | `TextHeightBehavior` | 控制行高前后空隙是否应用    | 用于处理多行文本顶部/底部 padding  | Web 与 iOS 行高差异常需用它修正 |


### 2.2 渲染流程

🔬 Text 渲染流程（源码级抽象）

```dart
Text
  ↓ build()
RichText
  ↓ createRenderObject()
RenderParagraph
  ↓ paint()
TextPainter
  ↓ layout()
Paragraph (engine 层)
  ↓ paint()
Skia 绘制
```

核心计算发生在：
 - `TextPainter.layout()`
 - `Paragraph.build() & layout()`


> 如果大量文本，建议使用类似`final _baseStyle = const TextStyle(fontSize: 14);`的方式定义基础样式，可以提高渲染效率。

### 2.3 代码示例

代码示例:

```dart
// 😄 基本使用
const Text(  // ✅ 正确用法：使用 const 优化静态文本
  "Hello Flutter",
  style: TextStyle(
    fontSize: 30, // 字体大小
    color: Colors.white, // 白色
    fontStyle: FontStyle.italic, // 斜体
    fontWeight: FontWeight.w700, // 加粗
    decoration: TextDecoration.underline, // 下划线
    decorationColor: Colors.white, // 下划线颜色
    decorationThickness: 3, // 下划线宽度
  )
)

// 😄 多行文本省略号显示
const Text("假如我是很长很长的文本",
  style: TextStyle(
    fontSize: 30, // 字体大小
    color: Colors.white, // 白色
  ),
  maxLines: 2, // 最多显示2行
  overflow: TextOverflow.ellipsis, // 超出部分省略号显示
),

// 😄 简单富文本
const Text.rich(
  TextSpan(
    text: 'Hello',
    style: TextStyle(
      fontSize: 30, // 字体大小
      color: Colors.red, // 红色
      fontWeight: FontWeight.w700, // 加粗
    ),
    children: [
      TextSpan(
        text: ' Flutter',
        style: TextStyle(
          // 没有设置字体大小，会继承父类的字体大小
          color: Colors.blue, // 蓝色
          fontWeight: FontWeight.w800, // 加粗
        ),
      ),
    ],
  ),
)


// ✅ 优化：使用 TextSpan 复用样式
final _baseStyle = const TextStyle(fontSize: 14);
ListView.builder(
  itemCount: 1000,
  itemBuilder: (context, index) {
    return RichText(
      text: TextSpan(
        style: _baseStyle, // 复用基础样式
        text: 'Item $index',
      ),
    );
  },
)
```
