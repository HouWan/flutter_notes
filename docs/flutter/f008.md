## 1.Stack/Positioned

`Stack` 是一个继承自 `MultiChildRenderObjectWidget` 的布局控件。`Stack`核心职责是：将多个子组件按堆叠(Z轴)的方式进行布局，并能控制子组件的相对定位(`Positioned`)和叠放顺序。

> `Positioned`继承自 `SingleChildRenderObjectWidget`，职责是：将子组件定位在 `Stack` 中的指定位置。


| 属性名               | 类型                  | 默认值    | 说明 |
| :---------------- | :------------------ | :------------------------------ | :--------------------------------------------- |
| **alignment**     | `AlignmentGeometry` | `.topStart` | 非 `Positioned` 子组件的对齐方式（相对于 Stack 区域）。  |
| **textDirection** | `TextDirection?`    | `null`  | 用于解析 `AlignmentDirectional` 中的方向（如 LTR / RTL）。 |
| **fit**           | `StackFit`          | `.loose`  | 控制非 `Positioned` 子组件的布局约束方式。 |
| **clipBehavior**  | `Clip`              | `.hardEdge` | 超出 Stack 边界时的裁剪行为。|
| **children**      | `List<Widget>`      | —  | 子组件列表，支持同时存在 `Positioned` 与普通 Widget。  |


**Positioned 额外属性（Stack 中定位子节点用）**

| 属性 | 类型 | 默认值 | 描述 | 源码级影响 |
|------|------|--------|------|-----------|
| **left** | `double` | `null` | 距左边界的距离 | 影响 `RenderStack._layoutPositionedChild` 的 `_getPosition` 计算 |
| **top** | `double` | `null` | 距顶边界的距离 | 同上，垂直方向定位 |
| **right** | `double` | `null` | 距右边界的距离 | 需要与 left 或 width 配合使用 |
| **bottom** | `double` | `null` | 距底边界的距离 | 需要与 top 或 height 配合使用 |
| **width** | `double` | `null` | 子Widget宽度 | 影响约束条件计算 |
| **height** | `double` | `null` | 子Widget高度 | 影响约束条件计算 |


**Stack 相关枚举与类说明：**

| 枚举 / 类                  | 作用                      | 常用值   |
| :---------------------- | :---------------------- | :------------------------------------- |
| **`StackFit`**          | 控制非 Positioned 子组件的布局大小 | - `loose`: 允许子组件按自身大小布局<br>- `expand`: 子组件尽可能扩展至父容器大小<br>- `passthrough`: 将父约束直接传递给子组件 |
| **`AlignmentGeometry`** | 控制非 Positioned 子组件的对齐方式 | - `Alignment.topLeft`<br>- `Alignment.center`<br>- `Alignment.bottomRight` 等  |
| **`Positioned`**        | Stack 专属定位子组件类  | 可设置 `left`, `right`, `top`, `bottom`, `width`, `height` |


**`StackFit` 不同模式对比：**

| 模式              | 行为描述              | 适用场景        |
| :-------------- | :---------------- | :---------- |
| **loose**       | 子组件按自身大小布局        | 一般默认选择      |
| **expand**      | 子组件强制扩展至 Stack 尺寸 | 填充型背景、遮罩层   |
| **passthrough** | 传递父约束，适用于特殊布局场景   | 特殊自定义容器内部布局 |


`Stack` 与 `Positioned` 的关系：
- ✅ 若子组件不使用 `Positioned`，则遵循 `Stack` 的 `alignment` 对齐规则；
- ✅ 若子组件被 `Positioned` 包裹，则完全由其位置参数决定位置。
- ✅ `Positioned`必须作为 `Stack` 的直接子组件。
- ✅ `Positioned`如果同时设置了`left`和`right`，则`width`会被忽略。同理，若同时设置了`top`和`bottom`，则`height`会被忽略。


它们的核心使用技巧与暗坑:
- 💡 金律一：谁在最下面，谁在最上面？
  - 在 `Stack(children: [...])` 的数组里，写在前面的组件在底层，写在后面的组件在顶层。这和 iOS 的 subviews 数组顺序一样的。

- 💡 金律二：`Positioned` 必须是 `Stack` 的 **直系亲属**，否则编译报错。

- 💡 金律三：不要把所有的子组件都用 `Positioned` 包裹
  - 非定位组件（Unpositioned Children）：没有被 `Positioned` 包裹的组件。`Stack` 的大小默认就是由最大的那个非定位组件决定的。
  - 定位组件（Positioned Children）：被 `Positioned` 包裹的组件，完全不占用 `Stack` 本身的空间计算，只根据设置的 `top/bottom/left/right` 悬浮在指定位置


**代码示例**

```dart
// 定位子组件示例
Stack(
  children: [
    Container(color: Colors.white, width: 200, height: 200),
    Positioned(
      // 放置到左上角，并距离左边 20 像素，距离顶部 20 像素
      left: 20,
      top: 20,
      child: Container(color: Colors.red, width: 80, height: 80),
    ),
    Positioned(
      // 放置到右下角，并距离右边 20 像素，距离底部 20 像素
      right: 20,
      bottom: 20,
      child: Container(color: Colors.red, width: 80, height: 80),
    ),
    Positioned( // 放置到中间区域，并距离左边 20 像素，距离顶部 20 像素，距离右边 20 像素，距离底部 20 像素
      right: 20,
      bottom: 20,
      top: 20,
      left: 20,
      child: Container(
        color: Colors.red.withAlpha(60),
        width: 80,
        height: 80,
      ),
    ),
  ],
)
```

一个复杂的卡片代码示例：
```dart
class _MyHomePageState extends State<MyHomePage> {
  @override
  Widget build(BuildContext context) {
    return Container(
      width: 280,
      height: 380,
      decoration: BoxDecoration(
        color: Colors.white,
        borderRadius: BorderRadius.circular(20),
        boxShadow: [
          BoxShadow(
            color: Colors.black.withValues(alpha: 0.25),
            blurRadius: 15,
            offset: const Offset(0, 8),
          ),
        ],
      ),
      child: ClipRRect(
        // 使用 ClipRRect 裁剪 Stack，防止子组件溢出圆角
        borderRadius: BorderRadius.circular(20),
        child: cardContent(),
      ),
    );
  }

  // 💡 核心在这里：使用 ClipRRect 裁剪 Stack，防止子组件溢出圆角

          height: double.infinity,

        // 2. 左上角“限定标签”（定位组件）
        Positioned(
          top: 12,
          left: 12,
          child: Container(
            padding: const EdgeInsets.symmetric(horizontal: 8, vertical: 4),
            decoration: BoxDecoration(
              gradient: const LinearGradient(
                colors: [Colors.amber, Colors.orange], // 渐变背景
              ),
              borderRadius: BorderRadius.circular(6),
            ),
            child: const Text(
              "限定皮肤",
              style: TextStyle(
                color: Colors.white,
                fontSize: 11,
                fontWeight: FontWeight.w500,
              ),
            ),
          ),
        ),

        // 3.右上角“收藏心形按钮”（定位组件）
        Positioned(
          top: 8,
          right: 8,
          child: IconButton(
            icon: const Icon(Icons.favorite, color: Colors.redAccent, size: 28),
            onPressed: () => debugPrint('点击了收藏'),
          ),
        ),

        // 4. 底部渐变遮罩层（定位组件）
        Positioned(
          bottom: 0, 
          left: 0,  // ⚠️技巧：l0+r0 就会 宽度拉伸至和 Stack 的宽度一模一样.
          right: 0,
          height: 100, // 固定这个渐变层的高度
          child: Container(
            decoration: const BoxDecoration(
              gradient: LinearGradient(
                begin: Alignment.bottomCenter,
                end: Alignment.topCenter,
                colors: [
                  Color.fromARGB(221, 232, 137, 4),
                  Colors.black45,
                  Colors.transparent, // 向上完美淡出到透明
                ],
              ),
            ),
          ),

        bottomView(),
      ],

  Widget bottomView() {  // 注意：不推荐这种抽的，建议抽成单独的 StatelessWidget 子类
    return Positioned(
      bottom: 16,
      left: 16,
      right: 16,
      child: Column(
        crossAxisAlignment: .start,
        mainAxisSize: MainAxisSize.min,
        children: [
          const Text(
            '赛博武士 · 零号',
            style: TextStyle(color: Colors.white, fontSize: 18),
          ),
          const SizedBox(height: 4),
          Row(
            children: List.generate(5, (i) {
              return Icon(Icons.star, color: Colors.amber, size: 14);
            }),
          ),
        ],
      ),
    );
  }
}
```

> 在规范的 Flutter 代码中，是极其不推荐把组件抽成一个类成员方法（如 `Widget bottomView()`），而是极度推崇把它们抽成独立的 `StatelessWidget` 子类。因为单独的`StatelessWidget` 子类才能真正的局部刷新，享受 `const` 的红利。


## 2.FittedBox

`FittedBox` 是 Flutter 中专门用来处理 按比例缩放与防内容溢出 的单子布局组件（Single-child Widget）。

它的核心能力是：获取子组件的原始尺寸（Intrinsic Size），并根据指定的 `fit` 模式对子组件进行整体等比例缩放（Scale），使其完美嵌入父组件提供的空间约束中。


> **iOS 开发者视角**：
> 1. 在 UIKit 中，`UIView.contentMode`（如 `.scaleAspectFit` / `.scaleAspectFill`）通常只对 `UIImageView` 生效。而 `FittedBox` 把这种 **Aspect Scale** 能力扩展到了 **任意 Widget**（包括 `Text`、`Row`、`Column` 或自定义视图）。
> 2. 配合 `BoxFit.scaleDown` 使用时，它就相当于 `UILabel.adjustsFontSizeToFitWidth = true` 的全局升级版（防止文本或卡片因字号过大/屏宽不够而抛出 `OVERFLOWED` 警告）。
> 

`FittedBox` 本身是一个单纯的布局组件，无复杂实例方法，核心控制完全依赖构造参数：


| 属性名 | 类型 & 默认值 | 作用说明 |
| --- | --- | --- |
| **`fit`** | `BoxFit` 默认值: `.contain` | **最关键属性**。定义子组件如何放缩以适应父视图尺寸。 |
| **`alignment`** | `AlignmentGeometry` 默认值: `.center` | 缩放后，子组件在 `FittedBox` 内部的**对齐位置**（如 `Alignment.centerLeft`）。 |
| **`clipBehavior`** | `Clip` 默认值: `.none` | 裁剪模式。当放缩规则导致内容超出父边界时（如 `BoxFit.cover`），是否裁剪超出的部分（如 `Clip.hardEdge`）。 |
| **`child`** | `Widget?` 默认值: `null` | 需要被整体缩放的目标子组件。 |

---


`fit` (BoxFit) 缩放模式详解:
* **`BoxFit.scaleDown`（最常用/防溢出神器）**：如果子组件尺寸**大于**容器，则**等比例缩小**以适应容器；如果子组件尺寸**小于**容器，则**保持原样**（不会被放大失真）。
* **`BoxFit.contain`（默认）**：无论子组件大或小，一律**等比例缩放**，直到有一条边贴合容器边界（保证内容完整展示，可能会留白）。
* **`BoxFit.cover`**：等比例缩放，直到**完全填满**容器（较短的边贴合，较长的边可能超出被裁剪）。
* **`BoxFit.fill`**：打破宽高比，拉伸变形以完全填满容器。

---

代码示例：

在电商 App 中，商品价格（如 ¥99999.00）在小屏设备上极易爆框。使用 `FittedBox(fit: BoxFit.scaleDown)` 可以在容器足够时显示原字号，不够时自动缩小字号：

```dart
@override
Widget build(BuildContext context) {
  return Container(
    width: 100, // 固定的卡片宽度
    height: 40,
    padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 4),
    color: Colors.red.shade50,
    child: FittedBox(
      // BoxFit.scaleDown: 文本短时保持 22pt，文本长时自动缩小字号，决不溢出
      fit: BoxFit.scaleDown,
      alignment: Alignment.centerLeft, // 缩小后靠左对齐
      child: Text(
        '¥${price.toStringAsFixed(2)}',
        style: const TextStyle(
          fontSize: 22, // 期望的大字号
          fontWeight: FontWeight.bold,
          color: Colors.red,
        ),
      ),
    ),
  );
}
```
