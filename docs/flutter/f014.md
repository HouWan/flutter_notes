## 1.ListView

`ListView` 继承自 `BoxScrollView`，本质上是对 `Scrollable` + `Viewport` + `SliverList` 的高层封装。对`ListView`的理解可以分为四个部分：构造函数（Constructors）、布局与尺寸控制、滚动与物理反馈 以及 性能与 Element 生命周期

> 继承关系是：`Widget` -> `StatelessWidget` -> `ScrollView` -> `BoxScrollView` -> `ListView`

### 1.1 常用构造函数 (Constructors)

| **构造函数** | **主要入参** | **作用说明** |
|---|---|---|
| `ListView(...)` | children: List<Widget> | **全量加载模式**。底层使用 `SliverChildListDelegate`。在 build 阶段一次性实例化所有 children Widget 并构建对应的 Element/RenderObject。仅适用于已知数量极少的静态列表。 |
| `ListView.builder(...)` | itemBuilder, itemCount | **按需懒加载模式**。底层使用 `SliverChildBuilderDelegate`。在 `Viewport` 布局阶段，只有进入 cacheExtent（缓存区）和可视区域的 Item 才会触发 itemBuilder 执行并构建 Element |
| `ListView.separated(...)` | itemBuilder, separatorBuilder, itemCount | **带分隔线的按需加载模式**。底层会将 itemBuilder 和 separatorBuilder 的数量交替翻倍计算（itemCount * 2 - 1），在 Element 树中按索引奇偶交替生成数据项与分隔线。 |
| `ListView.custom(...)` | childrenDelegate: SliverChildDelegate | **自定义 Delegate 模式**。允许直接传入自定义的 `SliverChildDelegate`（如自定义索引查找算法、复用逻辑或配合 Key 进行 Element 重用优化） |


### 1.2 ListView 最常用属性

#### 1.2.1 布局与尺寸控制属性

| 属性名称 | 类型&默认值 | 源码/原理级作用说明 |
| --- | --- | --- |
| **`scrollDirection`** | `Axis` 默认 `Axis.vertical` | 滚动主轴方向（`vertical` 或 `horizontal`）。决定了向子代传递约束时将哪一轴的 `maxConstraints` 设为 `double.infinite`。 |
| **`reverse`** | `bool` 默认 `false` | 是否反向布局。为 `true` 时，`RenderSliverList` 的绘制起点会翻转（如垂直列表改为从底部向上排列），滚动 offset 计算方向同步翻转。 |
| **`padding`** | `EdgeInsetsGeometry?` 默认 `null` | 内边距。源码中若不为空，会在内部将 `SliverList` 包裹一层 `SliverPadding`，内边距会在滚动内容的两端生效。 |
| **`itemExtent`** | `double?` 默认 `null` | **核心性能优化项**。固定每一个 Item 在主轴方向的高（或宽）。设置此值后，底层渲染树会切换为 **`RenderSliverFixedExtentList`**，跳过对各个子项的度量（Layout）过程，布局复杂度由 $O(N)$ 降低为 $O(1)$。 |
| **`prototypeItem`** | `Widget?` 默认 `null` | **固定尺寸代理项**。传入一个样板 Widget，底层根据该 Widget 测量出固定主轴尺寸后，切换为 **`RenderSliverPrototypeExtentList`**，效果同 `itemExtent` 但无需硬编码数值。 |
| **`shrinkWrap`** | `bool` 默认 `false` | **高危属性**。是否根据子组件的总长度来决定 `ListView` 的主轴尺寸。为 `true` 时会强制 `RenderViewport` 放弃占据最大可用空间，并触发对所有（或大量）Item 的测量，**严重破坏懒加载**。 |


#### 1.2.2 滚动控制与物理反馈属性

| 属性名称 | 类型&默认值 | 源码/原理级作用说明 |
| --- | --- | --- |
| **`controller`** | `ScrollController?` 默认 `null` | 滚动控制器。用于监听 `ScrollPosition` 的 `pixels` 变化或执行 `animateTo` / `jumpTo` 编程式滚动。 |
| **`primary`** | `bool?` 默认 `null` | 是否使用父级的 `PrimaryScrollController`。为 `true` 时，iOS 端点击系统状态栏会自动触发回顶（Scroll-to-top）。如果显式传入了 `controller`，则不能将 `primary` 设为 `true`。 |
| **`physics`** | `ScrollPhysics?` 默认 `null` | 滚动物理特性。控制阻尼、回弹及摩擦系数。iOS 默认匹配 `BouncingScrollPhysics`（允许 Overscroll），Android 默认匹配 `ClampingScrollPhysics` 或 `StretchScrollPhysics`。 |
| **`keyboardDismissBehavior`** | `ScrollViewKeyboardDismissBehavior` 默认 `manual` | 拖拽收起键盘行为。设为 `onDrag` 时，手势触发滚动的瞬间会通过 `FocusManager.instance.primaryFocus?.unfocus()` 强制收起软键盘。 |
| **`clipBehavior`** | `Clip` 默认 `Clip.hardEdge` | 内容溢出 Viewport 时的裁剪策略。默认为 `Clip.hardEdge`。在追求极致滚帧率时，若无溢出风险可设为 `Clip.none` 节省 Canvas 裁剪指令支出。 |


> `controller`属性和`SingleChildScrollView`的`controller`属性一样，都是`ScrollController`类型，用法也一样。


#### 1.2.3 性能与 Element 生命周期属性

| 属性名称 | 类型& 默认值 | 源码/原理级作用说明 |
| --- | --- | --- |
| **`cacheExtent`** | `double?` 默认 `250.0` | **预渲染缓冲区大小**（逻辑像素）。Viewport 在可视区域（Viewport Dimensions）前后各延伸 `cacheExtent` 距离。在此范围内的 Item 会被提前构建并完成 Layout，确保快速滑动时不白屏。 |
| **`addAutomaticKeepAlives`** | `bool` 默认 `true` | 是否自动为 Item 包裹 `AutomaticKeepAlive` Widget。配合子项的 `AutomaticKeepAliveClientMixin` 使用，使得移出 Viewport 的 Item 不会被销毁（ Element/RenderObject 保留在内存中）。 |
| **`addRepaintBoundaries`** | `bool` 默认 `true` | 是否自动为每一个 Item 包裹 `RepaintBoundary`。为 `true` 时，Item 会拥有独立的 `Layer`，滑动过程中的重绘不会污染其他 Item，但会消耗微量内存用于 Layer 管理。 |
| **`addSemanticIndexes`** | `bool` 默认 `true` | 是否自动包裹 `IndexedSemantics` 用于无障碍辅助功能（Accessibility/VoiceOver）。 |
| **`findChildIndexCallback`** | `int? Function(Key)?` 默认 `null` | **Key-Index 映射查找回调**。当列表数据发生重新排序（Reorder）或删除时，底层通过此回调找到 Key 对应的旧 Index，精确复用 Element，避免列表重排时整体重新重建（Rebuild）。 |

---

### 1.2 代码示例

**默认构造函数，适用于一次性加载所有项目**
```dart
@override
Widget build(BuildContext context) {
  return ListView(
    // controller: ,和`SingleChildScrollView`的`controller`属性一样，都是`ScrollController`类型，用法也一样。
    children: List.generate(20, (index) {
      return Container(
        margin: EdgeInsets.only(top: 6),
        color: Colors.blue,
        width: double.infinity,
        height: 80,
        alignment: .center,
        child: Text("第 $index 个", style: TextStyle(color: Colors.white)),
      );
    }),
  );
}
```

**`ListView.builder`构造函数，按需加载，类似iOS的`UITableView`。**
```dart
@override
Widget build(BuildContext context) {
  return ListView.builder(
    itemCount: 100, // 列表长度
    itemBuilder: (BuildContext context, int index) {  // 上下文和对应位置，返回 Widget
      return Container(
        margin: EdgeInsets.only(top: 10),
        color: Colors.blue,
        width: double.infinity,
        height: 60,
        alignment: .center,
        child: Text(
          "我是第 $index 个 Cell",
          style: TextStyle(color: Colors.white),
        ),
      );
    },
  );
}
```

**`ListView.separated`构造函数，按需加载，在`ListView.builder`的基础上，提供了构建分割线`separatorBuilder`的能力。**
```dart
@override
Widget build(BuildContext context) {
  return ListView.separated(
    itemCount: 100, // 列表长度
    itemBuilder: (BuildContext context, int index) { // 上下文和对应位置，返回 Widget
      return Container(
        color: Colors.blue,
        width: double.infinity,
        height: 60,
        alignment: .center,
        child: Text(
          "我是第 $index 个 Cell",
          style: TextStyle(color: Colors.white),
        ),
      );
    },
    separatorBuilder: (context, index) {  // cell 之间的 separator
      return Container(height: 10, width: double.infinity, color: Colors.red);
    },
  );
}
```


## 2.GridView

``GridView``是处理二维网格布局的核心滚动组件，类似 iOS 的`UICollectionView`，它的本质是 `Viewport` + `RenderSliverGrid` 的封装，将二维几何约束计算（`SliverGridDelegate`）与子节点懒加载（`SliverChildDelegate`）彻底解耦。

> 注意对于类似 个人标签 这种长度不固定，根据内容和屏幕宽度自动流式换行的场景，Flutter 中最标准且原生的组件是 `Wrap`。`GridView` 的核心定位是规整的网格矩阵，无法实现非等宽的流式瀑布/标签换行

### 2.1 常用属性和函数 

**1. 常用构造函数 (Constructors)**

| 构造函数 | 对应 Delegate | 源码/原理级作用说明 |
| --- | --- | --- |
| **`GridView(...)`** | 显式传入 `gridDelegate` + `SliverChildListDelegate` | **全量加载模式**。在 `build` 阶段一次性实例化所有 `children` Widget，对应 Element/RenderObject 全量生成。适用于已知数量且极少的卡片布局。 |
| **`GridView.builder(...)`** | 显式传入 `gridDelegate` + `SliverChildBuilderDelegate` | **按需懒加载模式**。Viewport 在 Layout 阶段仅对落入 `cacheExtent` 及可视区域内的 index 调用 `itemBuilder`，实现 Element/RenderObject 的动态创建与销毁。 |
| **`GridView.count(...)`** | 默认绑定 `SliverGridDelegateWithFixedCrossAxisCount` | **固定列数语法糖**。内部直接帮你实例化了按固定列数分割交叉轴的 Delegate，本质是全量加载。 |
| **`GridView.extent(...)`** | 默认绑定 `SliverGridDelegateWithMaxCrossAxisExtent` | **最大跨度语法糖**。根据交叉轴最大像素宽度（`maxCrossAxisExtent`）动态计算列数，自适应大屏/小屏。 |
| **`GridView.custom(...)`** | 显式传入 `gridDelegate` + 自定义 `SliverChildDelegate` | **高度自定义模式**。可自定义 Index 到 Key 的查找映射（`findChildIndexCallback`）以支持精准 Element 复用。 |

`gridDelegate`的两个值：
- `SliverGridDelegateWithFixedCrossAxisCount` 固定列数 `mainAxisSpacing` 主轴间距
- `SliverGridDelegateWithMaxCrossAxisExtent` 最大宽度 `crossAxisSpacing` 交叉轴间距


---

**2. 核心控制属性**

| 属性名称 | 类型 & 默认值 | 源码/原理级作用说明 |
| --- | --- | --- |
| **`gridDelegate`** | `SliverGridDelegate` **[必填]** | **网格几何算法核心**。负责在 Layout 阶段计算每个 child 的 `SliverGridGeometry`（确定在 2D 坐标系中的 `scrollOffset` 和 `crossAxisOffset`）。 |
| **`scrollDirection`** | `Axis` 默认 `Axis.vertical` | 滚动主轴方向。决定了哪个轴向提供 `double.infinite` 的约束，哪个轴向传递固定 Constraints。 |
| **`shrinkWrap`** | `bool` 默认 `false` | **高危属性**。设为 `true` 会强制 Viewport 计算所有子节点累加的总尺寸，破坏懒加载管线，引发全量 Layout/Build，造成滑动卡顿。 |
| **`cacheExtent`** | `double?` 默认 `250.0` | 预渲染缓冲区大小（逻辑像素）。在可视区域前后延伸该距离，提早触发 `itemBuilder` 并完成 Layout，避免快速滑动白屏。 |
| **`padding`** | `EdgeInsetsGeometry?`默认`null` | 外围内边距。源码中会自动转译为 `SliverPadding` 包裹在 `RenderSliverGrid` 外侧。 |
| **`physics`** | `ScrollPhysics?`默认`null` | 物理滚动反馈。iOS 对应 `BouncingScrollPhysics`，Android 对应 `ClampingScrollPhysics` / `StretchScrollPhysics`。 |

---

### 2.2 代码示例

**`GridView.count`创建固定列数/行数的网格布局, 全量加载。**

```dart
@override
Widget build(BuildContext context) {
  return GridView.count(
    scrollDirection: Axis.vertical,  // 滚动方向，默认是 垂直
    padding: EdgeInsets.all(10),
    mainAxisSpacing: 10,  // 主轴间距，垂直滚动时，就是行距
    crossAxisSpacing: 10,  // 交叉轴间距，垂直滚动时，就是列间距
    crossAxisCount: 3, // 列数或者行数，垂直滚动时，就是列数
    childAspectRatio: 1.5, // cell的宽高比，默认是 1，所以不设置这个值会显示正方形
    children: List.generate(8, (int index) {
      return Container(
        color: Colors.amberAccent,
        alignment: .center,
        child: Text("我是第 $index 个"),
      );
    }),
  );
}
```


**`GridView.extent`指定 cell 最大宽度或高度布局，并且随着屏幕宽度或高度的改变而改变列数或者行数, 全量加载。**，通过`maxCrossAxisExtent`设置 cell 的最大宽度/高度来计算水平或者垂直有多少列或者多少行。

```dart
@override
Widget build(BuildContext context) {
  return GridView.extent(
    maxCrossAxisExtent: 100,  // 指定cell 最大宽度或者高度，看 scrollDirection 方向。
    scrollDirection: Axis.vertical,
    padding: EdgeInsets.all(10),
    mainAxisSpacing: 10,
    crossAxisSpacing: 10,
    children: List.generate(8, (int index) {
      return Container(
        color: Colors.amberAccent,
        alignment: .center,
        child: Text("我是第 $index 个"),
      );
    }),
  );
}
```


**`GridView.builder`按需加载，需要传入`gridDelegate`、`itemCount`、`itemBuilder`参数。**

`gridDelegate`的两个值：
 - `SliverGridDelegateWithFixedCrossAxisCount` 固定列数/行数，对应`GridView.count`构造函数。
 - `SliverGridDelegateWithMaxCrossAxisExtent` Cell最大宽度，对应`GridView.extent`构造函数。

```dart
@override
Widget build(BuildContext context) {
  return GridView.builder(
    padding: EdgeInsets.all(10),
    gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
      crossAxisCount: 4,   // 列数或者行数，垂直滚动时，就是列数
      mainAxisSpacing: 10,  // 主轴间距，垂直滚动时，就是行距
      crossAxisSpacing: 10,  // 交叉轴间距，垂直滚动时，就是列间距
      childAspectRatio: 1.5, // cell的宽高比，默认是 1，所以不设置这个值会显示正方形
    ),
    itemCount: 100,
    itemBuilder: (BuildContext context, int index) {
      return Container(
        color: Colors.amberAccent,
        alignment: .center,
        child: Text("我是 $index 个", style: TextStyle(color: Colors.white)),
      );
    },
  );
}
```

## 3.CustomScrollView

`CustomScrollView` 是 Flutter 中直接操作 `Sliver` 体系 与 Viewport（视口） 的核心高阶滚动组件。与 `ListView` 不同，它不接受普通的 `RenderBox` 子节点，而是只接受协议为 `RenderSliver` 的 `Sliver` 组件，允许多个形态各异的滚动区域（如展开式 Appbar、网格、列表）共享同一个 `ScrollPosition` 和手势管线。

> `CustomScrollView` 的子节点必须是 `RenderSliver`。普通 `Widget`（继承自 `RenderObjectWidget` 且生成 `RenderBox`）无法解析 `SliverConstraints`，所以必须使用 **`SliverToBoxAdapter`** 将普通的 `RenderBox` 适配包装成 `RenderSliverSingleBoxAdapter`：
```dart
CustomScrollView(
  slivers: [
    const SliverToBoxAdapter(
      child: SizedBox(height: 100, child: Text('常规 Header')),
    ),
    SliverList(...),
  ],
)
```


**CustomScrollView 常用属性表**

| 属性名称 | 类型 & 默认值 | 源码/原理级作用说明 |
| --- | --- | --- |
| **`slivers`** | `List<Widget>` **[必填] `const []**` | **核心槽位**。只能接收 Sliver 族 Widget（如 `SliverList`、`SliverGrid`、`SliverAppBar`、`SliverToBoxAdapter`）。在 Layout 阶段，这些组件会转化为 `RenderSliver` 节点。 |
| **`scrollDirection`** | `Axis`默认`Axis.vertical` | 滚动主轴方向。决定 Viewport 向内部各 Sliver 传递 `SliverConstraints` 时的轴向基准。 |
| **`reverse`** | `bool`默认`false` | 是否反向沿主轴排列。若为 `true`，Viewport 的 `scrollOffset = 0` 将位于轴向尾部（如底部或最右侧）。 |
| **`controller`** | `ScrollController?`默认`null` | 滚动控制器。绑定该 Viewport 的 `ScrollPosition`，用于监听 `pixels` 变化或执行编程式滚动（如 `animateTo`）。 |
| **`primary`** | `bool?`默认`null` | 是否关联到根部的 `PrimaryScrollController`。在 iOS 上为 `true` 时，点击系统状态栏会自动触发出 `ScrollToTop`。 |
| **`physics`** | `ScrollPhysics?`默认`null` | 物理滚动阻尼。iOS 匹配 `BouncingScrollPhysics`（支持 Overscroll），Android 匹配 `ClampingScrollPhysics` / `StretchScrollPhysics`。 |
| **`center`** | `Key?`默认`null` | **双向/双向增长滚动核心**。传入 `slivers` 中某个 Sliver 的 `Key`，将该 Sliver 指定为 `scrollOffset = 0` 的基准锚点（起点），使其支持向正负两个方向延伸。 |
| **`anchor`** | `double`默认`0.0` | **基准锚点在 Viewport 中的相对偏移**（取值 `0.0 ~ 1.0`）。`0.0` 表示 `center` 位于视口头部，`0.5` 表示位于视口正中央。 |
| **`cacheExtent`** | `double?`默认`250.0` | 预渲染缓冲区大小（逻辑像素）。Viewport 在可视区域前后额外延伸此距离，令处于该区域内的 Sliver 提前进行 Element 构建与 Layout，避免快速滑动时白屏。 |
| **`shrinkWrap`** | `bool`默认`false` | **高危属性**。为 `true` 时底层将改用 `ShrinkWrappingViewport`，强制计算所有 Slivers 的总尺寸，导致懒加载失效与严重的 Layout 性能下挫。 |
| **`keyboardDismissBehavior`** | `ScrollViewKeyboardDismissBehavior`默认`manual` | 键盘收起策略。设为 `onDrag` 时，用户手势拖拽 Viewport 的瞬间触发 `FocusManager` 解绑焦点并收起软键盘。 |
| **`clipBehavior`** | `Clip`默认`Clip.hardEdge` | 内容超出 Viewport 时的 Canvas 裁剪策略。若能确保内部子项均不溢出，设为 `Clip.none` 可节省渲染管线中的离屏裁剪指令支出。 |

---

**CustomScrollView 关键方法表**

`CustomScrollView` 继承自 `ScrollView`（`StatelessWidget`），其核心逻辑在于构建 Viewport 树。

| 方法名称 | 返回类型 | 源码/原理级作用说明 |
| --- | --- | --- |
| **`buildSlivers(BuildContext context)`** | `List<Widget>` | **保护级方法**。直接返回构造时传入的 `slivers` 数组。若继承 `CustomScrollView` 自定义高级组件，可重写此方法动态注入全局 Header/Footer。 |
| **`buildViewport(...)`** | `Widget` | **视口构建核心**。若 `shrinkWrap = false`，实例化并返回 **`Viewport`** 节点；若 `shrinkWrap = true`，则实例化 **`ShrinkWrappingViewport`** 节点。 |

---


`Sliver`组件对应关系：
 - `SliveList` --> `ListView`
 - `SliveGrid` --> `GridView`
 - `SliveAppBar` --> `AppBar`
 - `SlivePadding` --> `Padding`
 - `SliveToBoxAdapter` --> `ToBoxAdapter`用于包裹普通 Widget
 - `SlivePersistentHeader` 粘性吸顶



代码示例：
```dart
@override
Widget build(BuildContext context) {
  return CustomScrollView(
    slivers: [  // 里面必须是 SliverXxx 包裹的子组件
      SliverToBoxAdapter(
        child: Container(
          color: Colors.blueAccent,
          alignment: .center,
          height: 200,
          child: const Text("轮播图区域", style: TextStyle(color: Colors.white)),
        ),
      ),
      const SliverToBoxAdapter(child: SizedBox(height: 10)), // 充当间距
      SliverPersistentHeader(pinned: true, delegate: _StickyCategory()), // 自动吸附
      const SliverToBoxAdapter(child: SizedBox(height: 10)), // 充当间距
      SliverList.separated(
        itemCount: 30,
        itemBuilder: (c, i) {
          return Container(
            color: Colors.pink,
            height: 48,
            alignment: .center,
            child: Text("我是第 $i 个", style: TextStyle(color: Colors.white)),
          );
        },
        separatorBuilder: (c, i) => SizedBox(height: 20),
      ),
    ],
  );
}

// 创建一个实现 SliverPersistentHeaderDelegate 协议的类，并实现对应方法
class _StickyCategory extends SliverPersistentHeaderDelegate {
  @override
  Widget build(
    BuildContext context,
    double shrinkOffset,
    bool overlapsContent,
  ) {
    return Container(
      color: Colors.green,
      child: ListView.separated(
        scrollDirection: .horizontal,
```
