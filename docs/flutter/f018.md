跨域（CORS - Cross-Origin Resource Sharing）是开发阶段最常遇到的问题，下面本地开发时解决/绕过跨域问题的解决办法：

**方案 1：启动 Flutter 时关闭 Chrome 安全策略（最推荐、最快捷）**

在本地开发调试阶段，可以通过向 Chrome 传递 `--disable-web-security` 命令行参数，让 Chrome 暂时停用同源策略检查。

**方法 A：命令行直接运行**
在终端中使用以下命令启动项目：
```bash
flutter run -d chrome --web-browser-flag "--disable-web-security"
```


**方法 B：在 VS Code 中配置（按 F5 一键启动）**
如果你使用的是 VS Code，可以在项目根目录下的 `.vscode/launch.json` 中添加如下配置：
```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Flutter Web (无跨域)",
      "request": "launch",
      "type": "dart",
      "args": [
        "-d",
        "chrome",
        "--web-browser-flag",
        "--disable-web-security"
      ]
    }
  ]
}
```

> 注意：启动时 Chrome 顶部可能会显示 “您使用的是不受支持的命令行标记...” 的黄色警告条，直接忽略即可。

**方案 2：服务端配置响应头（根本解决方案）**

后端需要在 HTTP 响应头（Response Headers）中添加以下信息：
```http
Access-Control-Allow-Origin: *   (或指定本地开发端口，如 http://localhost:5000)
Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS
Access-Control-Allow-Headers: Authorization, Content-Type, X-Requested-With
```

**方案 3：修 Flutter SDK 配置文件**
在本地 Flutter SDK 目录中，找到下面这个文件。：
```
flutter_sdk/packages/flutter_tools/lib/src/web/chrome.dart 
```

在下面位置添加 `--disable-web-security`命令：
```dart
final int port = debugPort ?? await _operatingSystemUtils.findFreePort();
final args = <String>[
  chromeExecutable,
  // Using a tmp directory ensures that a new instance of chrome launches
  // allowing for the remote debug port to be enabled.
  '--user-data-dir=${userDataDir.path}',
  '--remote-debugging-port=$port',
  // When the DevTools has focus we don't want to slow down the application.
  '--disable-background-timer-throttling',
  // Since we are using a temp profile, disable features that slow the
  // Chrome launch.
  '--disable-extensions',
  '--disable-popup-blocking',
  '--bwsi',
  '--no-first-run',
  '--no-default-browser-check',
  '--disable-default-apps',
  '--disable-translate',
  '--disable-web-security',  // 添加的命令

  // Remove the search engine choice screen. It's irrelevant for app
  // debugging purposes.
  // See: https://github.com/flutter/flutter/issues/153928
  '--disable-search-engine-choice-screen',

  if (headless) ...<String>['--no-sandbox', '--headless', '--window-size=2400,1800'],
  ...webBrowserFlags,
  url,
];
```

然后删除 `flutter/bin/cache`下`flutter_tools.snaphot`和`flutter_tools.stamp`文件，

之后，运行`flutter doctor -v` 重新运行项目。
