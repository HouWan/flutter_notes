
## 1.TextField

### 1.1 `TextField` 常用属性:

| 属性  | 类型 | 说明  | 底层机制（原理级） | 常见误区 & 最佳实践 |
| ----------------- | ----------------- | ----------------- | ------------------- | ------------ |
| **controller**  | `TextEditingController?`  | 用于控制 `TextField` 的文本内容。可通过它获取和设置文本 | `TextEditingController` 会监听文本的变化，并通过 `TextInput` 与底层平台进行交互 | 在使用 `TextEditingController` 时，⚠️记得在 `dispose()` 中手动释放💄  |
| **focusNode** | `FocusNode?`  | 用于管理 `TextField` 的焦点状态（是否获得输入焦点） | `FocusNode` 会与平台进行交互来处理焦点变化，触发键盘弹出或收回等操作 | 若有多个 `TextField`，使用 `FocusNode` 来管理焦点切换  |
| **keyboardType**  | `TextInputType?`  | 定义键盘的类型，如：`.text`, `.number` | 根据不同的 `keyboardType`，底层会调用平台的输入法来显示相应的键盘类型 | 例如：设置 `.number` 时会弹出数字键盘 |
| **obscureText** | `bool`  | 是否隐藏文本（常用于密码输入框）  | 会触发底层输入法的显示模式，以隐藏文本的明文显示 | 常用于密码字段，确保隐私保护 |
| **style** | `TextStyle?`  | 用于设置输入文本的样式，包括字体、大小、颜色等  | 通过 `TextPainter` 来渲染文本样式，影响文本的绘制 | 提供合适的样式和布局 |
| **decoration**  | `InputDecoration?`  | 输入框的装饰，如：边框、提示文本、图标等 | `InputDecoration` 是一个高度自定义的 UI 元素，内部分为多个小部件来构建界面 | 用于定制非常复杂的输入框样式  |
| **onChanged** | `ValueChanged<String>?` | 当文本变化时回调，接收当前文本值 | 每次文本输入变化时会触发回调函数 | 适用于实时获取文本变化并进行处理 |
| **onSubmitted** | `ValueChanged<String>?` | 当用户提交（通常是按下回车键）时触发的回调  | 监听提交事件，通常用于提交表单或触发搜索功能 | 用于表单的提交逻辑 |
| **enabled** | `bool?` | 控制 `TextField` 是否可用（禁用时不可编辑） | 当设置为 `false` 时，内部组件会被禁用并且无法交互  | 在禁用状态下，TextField 将无法接收输入 |
| **maxLength** | `int?`  | 设置最大输入长度  | 会限制用户输入的字符数，当输入达到 `maxLength` 后不能继续输入  | `maxLength` 可以结合 `inputFormatters` 限制输入字符的类型 |
| **inputFormatters** | `List<TextInputFormatter>?` | 输入格式化器，用于限制输入的格式（例如限制为数字或字母） | 通过 `TextInputFormatter` 可以对输入进行校验或转换 | 常用来限制输入字符的类型（如只允许输入数字） |
| **autofocus** | `bool`  | 设置 `TextField` 是否自动获得焦点  | 如果设置为 `true`，则该 `TextField` 会在页面加载时自动获得焦点并弹出键盘 | 如果有多个 `TextField`，避免设置多个 `autofocus`，否则会导致意外行为 |
| **maxLines**  | `int?`  | 设置 `TextField` 的最大行数 | 控制文本框的最大高度，如果文本超过最大行数，则会滚动显示 | 适用于多行输入框（如备注、评论框等） |
| **minLines**  | `int?`  | 设置 `TextField` 的最小行数 | 当文本较少时，保证至少显示指定行数  | 与 `maxLines` 配合使用，调整多行文本框的大小 |
| **textAlign** | `TextAlign?` | 文本对齐方式，如：`.left`, `.center`, `.right` | 控制文本在 `TextField` 中的水平对齐 |  |
| **cursorWidth** | `double?` | 光标宽度 | 控制光标在 `TextField` 中的宽度 |  |
| **cursorHeight** | `double?` | 光标高度 | 控制光标在 `TextField` 中的高度 |  |
| **cursorRadius** | `Radius?` | 光标圆角半径 | 控制光标在 `TextField` 中的圆角半径 |  |


> 使用 `TextField` 时，需要使用 `StatefulWidget` 来管理文本输入状态。这是因为 `TextField` 是一个有状态的小部件，它需要维护文本输入的状态，如当前输入的文本内容、光标位置等。

### 1.2 TextField代码演示

代码示例:
```dart
class _MyHomePageState extends State<MyHomePage> {
  // 1. 声明控制器：用来监听文本变化、获取/设置文本内容（类似 iOS 的 Text 的 Delegate/Binding）
  late final TextEditingController _phoneController;
  late final TextEditingController _passwordController;

  // 2. 声明焦点对象：用来控制键盘的弹起、收回、以及焦点跳转
  late final FocusNode _phoneFocusNode;
  late final FocusNode _passwordFocusNode;

  // 3. 状态变量：控制密码是否明文显示
  bool _isPasswordObscure = true;

  @override
  void initState() {
    super.initState();

    // 初始化控制器和焦点
    _phoneController = TextEditingController(); // 初始化传 text，则自动显示到输入框
    _phoneFocusNode = FocusNode();

    _passwordController = TextEditingController();
    _passwordFocusNode = FocusNode();

    // 💡 高级技巧：可以单独给控制器加监听，实时捕获用户输入
    _phoneController.addListener(() {
      // 💡 比如 在这里做手机号格式的实时校验
      setState(() {}); // 触发刷新是为了让“清除按钮”根据文字有无来动态显示
    });
  }

  @override
  void dispose() {
    // ⚠️ 铁律：控制器和焦点用完必须销毁，否则会造成严重的内存泄露！
    _phoneController.dispose();
    _phoneFocusNode.dispose();

    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    // 💡 GestureDetector 体验优化：点击空白处，自动收起键盘（Native 开发的标配优化）
    return GestureDetector(
      child: SingleChildScrollView(
        // 键盘出来，不会遮挡或压缩内容
        padding: const EdgeInsets.all(26),
        child: pageContent(context),
      ),
    );
  }

  Widget pageContent(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.stretch,
      children: [
        const Text(
          "Hello，登录",
          style: TextStyle(fontSize: 25, fontWeight: .bold),
        ),
        const SizedBox(height: 24),
        phoneInputWidget(context), // 手机号输入区域
        const SizedBox(height: 20),
        passwordInputWidget(context), // 密码输入区
        const SizedBox(height: 30),
        ElevatedButton(
          onPressed: () {
            // 💡 核心技巧：通过 controller.text 就能直接拿到用户的输入字符串
            String phone = _phoneController.text;
            String password = _passwordController.text;
            debugPrint('提交数据 -> 手机号: $phone, 密码: $password');
          },
          style: ElevatedButton.styleFrom(
            padding: const EdgeInsets.symmetric(vertical: 18),
          ),
          child: Text("登录", style: TextStyle(fontSize: 18)),
        ),
      ],
    );
  }

  // 📱 手机号输入框（基础属性与格式限制演示）
  Widget phoneInputWidget(BuildContext context) {
    return TextField(
      controller: _phoneController, // 绑定控制器
      focusNode: _phoneFocusNode, // 绑定焦点
      keyboardType: TextInputType.phone, // 弹出数字电话键盘
      textInputAction: TextInputAction.next, // 键盘右下角显示“下一步”按钮
      onSubmitted: (_) {
        // 当用户点击键盘上的“下一步”时，自动将焦点跳转到密码框
        FocusScope.of(context).requestFocus(_passwordFocusNode);
      },
      // 💡 核心属性：输入限制。只允许输入数字，且最多只能输入 11 位
      inputFormatters: [
        FilteringTextInputFormatter.digitsOnly, // 只允许纯数字
        LengthLimitingTextInputFormatter(11), // 限制最大长度为 11 位
      ],
      cursorColor: Colors.blue, // 光标颜色
      cursorWidth: 2.0, // 光标宽度
      style: const TextStyle(fontSize: 16, color: Colors.black87), // 输入文字的样式
      // 🎨 核心属性：UI 皮肤美化（InputDecoration）
      decoration: InputDecoration(
        contentPadding: EdgeInsets.only(left: 10, right: 10), // 文本边距
        labelText: '手机号码', // 浮动标签（当输入框有文字或获取焦点时会缩小移到上方）
        labelStyle: TextStyle(color: Colors.grey), // 浮动标签，默认颜色
        floatingLabelStyle: TextStyle(color: Colors.blue), // 浮动标签，浮动时的颜色
        hintText: '请输入11位手机号', // 占位提示文字（类似 iOS 的 placeholder）
        hintStyle: TextStyle(color: Colors.grey), // 提示文本颜色/字体
        prefixIcon: const Icon(Icons.phone_android), // 输入框左侧的图标
        // 💡 动态后缀组件：只有当输入框有文字时，才显示“一键清除”的叉叉按钮
        suffixIcon: _phoneController.text.isNotEmpty
            ? IconButton(
                icon: const Icon(Icons.clear, size: 20),
                onPressed: () => _phoneController.clear(), // 清空输入框
              )
            : null,

        // 各种状态下的边框定制：
        border: const OutlineInputBorder(), // 默认的矩形边框
        enabledBorder: OutlineInputBorder(
          // 未获取焦点时的边框颜色
          borderSide: BorderSide(color: Colors.grey[400]!),
          borderRadius: BorderRadius.circular(12),
        ),
        focusedBorder: OutlineInputBorder(
          // 获取焦点（正在输入）时的边框颜色和粗细
          borderSide: const BorderSide(color: Colors.blue, width: 2),
          borderRadius: BorderRadius.circular(12),
        ),
        filled: true, // 只有 true 时，fillColor 才生效
        fillColor: Colors.white, // 输入框背景色
      ),
    );
  }

  // 🔒 密码输入框（明暗文切换演示）
  Widget passwordInputWidget(BuildContext context) {
    return TextField(
      controller: _passwordController,
      focusNode: _passwordFocusNode,
      keyboardType: TextInputType.visiblePassword, // 密码类型
      textInputAction: TextInputAction.done, // 键盘右下角显示“完成”按钮
      onSubmitted: (_) {
        // 点击完成，直接收起键盘
        _passwordFocusNode.unfocus();
      },
      obscureText: _isPasswordObscure, // 💡 核心属性：为 true 时开启密码隐藏显示（***）
      obscuringCharacter: '•', // 隐藏时替换的符号，默认就是圆点

      decoration: InputDecoration(
        labelText: '登录密码',
        hintText: '请输入密码',
        prefixIcon: const Icon(Icons.lock_outline),

        // 💡 动态控制密码可见性的按钮
        suffixIcon: IconButton(
          icon: Icon(
            _isPasswordObscure ? Icons.visibility_off : Icons.visibility,
          ),
          onPressed: () {
            // 切换状态改变明暗文
            setState(() {
              _isPasswordObscure = !_isPasswordObscure;
            });
          },
        ),
        enabledBorder: OutlineInputBorder(
          borderSide: BorderSide(color: Colors.grey[400]!),
          borderRadius: BorderRadius.circular(12),
        ),
        focusedBorder: OutlineInputBorder(
          borderSide: const BorderSide(color: Colors.blue, width: 2),
          borderRadius: BorderRadius.circular(12),
        ),
        filled: true,
        fillColor: Colors.white,
      ),
    );
  }
}
```

### 1.3 TextField 注意点：

**1.为什么一定要手动 dispose Controller 和 FocusNode？**

iOS 中，`UITextField` 的生命周期通常随 `UIViewController` 自动销毁。但在 Flutter 中，`TextEditingController` 和 `FocusNode` 底层其实是对系统全局通道（`MethodChannel`）的观察者订阅。如果你在组件销毁时不手动调用 `.dispose()`，这个订阅就会常驻内存，导致整个页面无法被垃圾回收（GC），从而引发内存泄露。


**2. `onChanged` 回调 vs `Controller.addListener`**
- 如果只是想单纯获取当前输入的最新字符串（比如查一下字数），直接用 `TextField(onChanged: (text) { ... })` 性能最好
- 如果你不仅要监听变化，还要做动态清空、外部主动改写输入框内容、监听焦点失去/获得等复杂控制，必须上 `TextEditingController`。

**3.键盘弹起导致布局溢出（Bottom Overflowed）**

在 iOS 里键盘弹起会挡住 UI，我们需要手动监听键盘高度去改常数。在 Flutter 中，默认情况下键盘弹起会自动挤压页面空间。
- 如果你的页面是用普通的 `Column` 裸奔写的，键盘一旦弹起，空间变小，就会 `Bottom Overflowed by XXX pixels` 报错
- **解决死律**：只要页面有 `TextField`，外层必须包裹一层 `SingleChildScrollView`。这样键盘弹起时，整个页面会自动获得像 `UIScrollView` 一样的滚动能力，完美规避溢出 Bug。

## 2.SingleChildScrollView

### 2.1 常用属性


`SingleChildScrollView` 继承自 `StatelessWidget`，它本质上是对底层 `Scrollable` 和 `RenderViewport` 系列组件的封装。以下是其最核心的属性：

| 属性名称 | 类型 | 默认值 | 源码/原理级作用说明 |
| --- | --- | --- | --- |
| **`scrollDirection`** | `Axis` | `Axis.vertical` | 定义滚动轴向。决定了向子代传递约束时，**哪一个轴向的 `maxConstraints` 会被改为 `double.infinite**`。 |
| **`reverse`** | `bool` | `false` | 是否反向滚动。若为 `true`，阅读起点会移到尾部（如垂直滚动的底部），常用于聊天信息流。 |
| **`padding`** | `EdgeInsetsGeometry?` | `null` | 内边距。源码中若检测到 `padding` 不为空，会自动在 `child` 外部包裹一层 `SliverPadding`。 |
| **`primary`** | `bool?` | `null` | 是否作为关联到父级 `PrimaryScrollController` 的主滚动视图。为 `true` 时，iOS 端点击状态栏会自动回顶（Scroll-to-top）。 |
| **`physics`** | `ScrollPhysics?` | `null` | 滚动物理反馈。控制边界回弹（Bouncing）、微调阻尼（Clamping）等。不指定时会根据当前 `Theme` 的 `TargetPlatform` 自动匹配。 |
| **`controller`** | `ScrollController?` | `null` | 滚动控制器。用于监听滚动偏移量 `offset` 或编程式控制滚动（如 `animateTo`）。**不能与 `primary: true` 共存**。 |
| **`dragStartBehavior`** | `DragStartBehavior` | `DragStartBehavior.start` | 确定手势识别器何时开始计入滚动。`start` 会从接触点突变触发，`down` 会从按下瞬间更平滑地捕获。 |
| **`clipBehavior`** | `Clip` | `Clip.hardEdge` | 裁剪行为。当子组件超出 `SingleChildScrollView` 自身边界时的裁剪算法（`hardEdge` / `antiAlias` / `none`）。 |
| **`keyboardDismissBehavior`** | `ScrollViewKeyboardDismissBehavior` | `manual` | 键盘收起策略。可设置为 `onDrag`，在用户开始拖拽滚动视图时自动收起软键盘。 |


### 2.2 注意点

**坑 1：与 Flex 组件（`Column`/`Row`）的“无限高度”冲突**

```dart
// ❌ 错误示范：会导致 Layout 阶段抛出 A RenderFlex overflowed... 或 Boundless height 异常
SingleChildScrollView(
  child: Column(
    children: [
      Expanded( // ❌ 崩溃点：Expanded 要求填满剩余空间，但上层给了无限空间
        child: Container(color: Colors.red),
      ),
    ],
  ),
)
```

- **原因分析**：`SingleChildScrollView` 给 `Column` 传了 `maxHeight: double.infinite`。`Column` 收到后，发现里面有个 `Expanded`。`Expanded` 的本质是分配剩余空间，但在无限空间里，“剩余空间”也是无限的，`Column` 无法计算出具体尺寸，直接抛出断言异常

- **解法**：在 `SingleChildScrollView` 内部，绝不能直接使用 `Expanded` 或 `Spacer`。如果需要让` Column` 至少填满屏幕（不足时填满，超长时滚动），必须配合 `LayoutBuilder` 和 `ConstrainedBox`

----

**坑 2：内存与掉帧巨坑**

- 场景：很多开发者为了图方便，直接用 `SingleChildScrollView` + `Column` 代替 `ListView` 来展示列表数据。
- 真机代价：当数据量超过几页时，由于缺乏 `Viewport` 的复用机制（iOS 中类似 `UITableView` 的 `dequeueReusableCell`），内存线会飙升，且在滑动时，由于大量 `RenderObject` 隐式参与重绘（Repaint），会导致严重的丢帧。
- 最佳实践：只有在处理固定布局（如：用户注册表单、设置页面、弹窗内容展示）且内容可能在小屏手机上溢出时，才使用 `SingleChildScrollView`。对于动态长列表，必须使用 `ListView.builder` 或 `CustomScrollView`


### 2.3 代码示例

**1.最基础的垂直滚动示例**
```dart
@override
Widget build(BuildContext context) {
  return SingleChildScrollView(
    padding: const EdgeInsets.all(16.0),
    physics: const BouncingScrollPhysics(), // 弹性滚动，有回弹效果
    child: Column(
      children: List.generate(
        10,
        (index) => Container(
          height: 300,
          color: getRandomColor(),
          child: Center(child: Text('方块 $index')),
        ),
      ),
    ),
  );
}

Color getRandomColor() {
  final r = Random();
  return Color.fromARGB(255, r.nextInt(256), r.nextInt(256), r.nextInt(256));
}
```

**2.最基础的横向滚动**
```dart
@override
Widget build(BuildContext context) {
  return SizedBox(
    height: 150, // 给水平滚动视图一个固定的高度
    child: SingleChildScrollView(
      scrollDirection: Axis.horizontal, // 水平滚动
      padding: const EdgeInsets.symmetric(horizontal: 16.0), // 水平方向的内边距
      child: Row(
        children: List.generate(
          10,
          (index) => Container(
            width: 120,
            height: double.infinity,
            color: getRandomColor(),
            alignment: Alignment.center,
            child: Text(
              index.toString(),
              style: const TextStyle(fontSize: 24, color: Colors.white),
            ),
          ),
        ),
      ),
    ),
  );
}
```

> 通常需要用 `SizedBox` 或 `Container` 给 `SingleChildScrollView` 限制一个高度，否则 `Row` 在垂直方向不知道自己该撑多大

**3.控制滚动**

```dart
class _MainPageState extends State<MainPage> {
  // 滚动控制Controller
  final ScrollController _scrollController = ScrollController();

  @override
  Widget build(BuildContext context) {
    return Stack(
      children: [
        SingleChildScrollView(
          padding: EdgeInsets.all(20),
          controller: _scrollController,
          child: Column(
            children: List.generate(30, (index) {
              return Container(
                width: double.infinity,
                height: 90,
                margin: EdgeInsetsDirectional.only(top: 10),
                color: Colors.blue,
                alignment: .center,
                child: Text(
                  "我是第 $index 个",
                  style: TextStyle(color: Colors.white, fontSize: 20),
                ),
              );
            }),
          ),
        ),
        // 放置堆叠按钮
        Positioned(
          bottom: 20,
          right: 15,
          child: GestureDetector(
            onTap: _scrollToTop,
            child: Container(
              decoration: BoxDecoration(
                color: Colors.red,
                borderRadius: BorderRadius.circular(40),
              ),
              width: 80,
              height: 80,
              alignment: .center,
              child: Text("去顶部", style: TextStyle(color: Colors.white)),
            ),
          ),
        ),
      ],
    );
  }

  void _scrollToTop() {
    // 触发滚动前做 hasClients 检查
    if (_scrollController.hasClients && _scrollController.offset > 0) {
      // _scrollController.jumpTo(0);  这不带动画效果
      _scrollController.animateTo(
        0.0,
        duration: Duration(seconds: 1),
        curve: Curves.bounceIn,
      );
    }
  }

  @override
  void dispose() {
    _scrollController.dispose(); // 必须优先或正常释放，防止内存泄漏
    super.dispose();
  }
}
```
