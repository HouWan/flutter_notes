## 1.图片资源

### 1.1 配置 pubspec.yaml

在 Flutter 项目中正确配置 `pubspec.yaml`，才可以加载bundle图片，例如项目结构如下：

```text
我的Flutter项目/
├── android/
├── assets/          # 我新建的资源文件夹
│   └── images/      # 建议的子文件夹，存放图片
│       ├── my_icon.png
│       └── background.jpg
├── ios/
├── lib/
│   └── main.dart
└── pubspec.yaml     # 必须在此文件声明资源
```

对于不同倍率的图片，应该使用`2.0x`、`3.0x`文件夹存放：

```text
my_first_demo/
├── assets/
│   └── images/
│       ├── dog.png       ← 把 dog@2x.png 复制一份到这里，重命名为 dog.png（作为基准版本）
│       ├── 2.0x/
│       │   └── dog.png   ← 你的 dog@2x.png，去掉 @2x 后缀
│       └── 3.0x/
│           └── dog.png   ← 你的 dog@3x.png，去掉 @3x 后缀
├── pubspec.yaml
```

**要点：**
- 文件夹名必须是 `2.0x`、`3.0x`（注意是 `2.0x` 不是 `2x`，有小数点）
- 三个文件都叫 `dog.png`，靠文件夹区分倍率
- 根目录 `dog.png` 是"基准版本"**⚠️必须有⚠️**，*没有 `1x` 原图，把 `2x` 复制一份放这里就行，演示阶段不影响*



在 `pubspec.yaml` 文件中添加 `assets` 声明：
```yaml
flutter:
  uses-material-design: true

  # ⚠️注意缩进：YAML 对缩进敏感
  assets: # ⚠️注意这里的 assets 和 下面路径中的 assets 概念不一样
    # 声明单个文件 (项目根目录下的 assets/images/my_icon.png)
    - assets/images/my_icon.png
    # 声明整个目录（注意结尾的 `/`）
    - assets/images/
    # 声明 lib/images/ 目录下的所有文件（注意结尾的 `/`）
    - lib/images/
```

> ⚠️修改 `pubspec.yaml` 后，必须在终端执行 `flutter pub get`，或在IDE中点击提示的 `Pub get` 按钮使配置生效. VS Code 通常会自动跑 `flutter pub get`。如果没有，命令面板` ⌘⇧P` → `Flutter: Get Packages` 手动跑一次。



将 `assets/images/my_icon.png` 图片显示在 `Widget` 中：
```dart

// 加载 Image 资源
AssetImage("assets/images/my_icon.png")
// 或者
AssetImage("images/my_icon.png")


// Widget
@override
Widget build(BuildContext context) {
  return Center(child: Image.asset("assets/images/dog.png"));
}
```

> 图片的格式支持：png、jpg、webp等，Flutter 在构建时会自动根据设备的设备像素比（Device Pixel Ratio， DPR）从相应目录中选取最匹配的图片并打包

### 1.2 图片包体积问题

因为基准版本必须有（因为基本不会有 1x 的设备了，我们会使用 2x 代替），如果再有 `2.0x` 和 `3.0x`文件夹，则会多了一个份 2x 图，对此三种方案，按"包体积友好度"从高到低排：

> 因为支持 webp 格式，尽量使用webp 格式的 icon

**方案 1**（最省体积，最推荐）：只放一份，不分子文件夹

```md
assets/images/
  dog.png   ← 直接放 @3x 那张
```

在`yaml`文件中：
```yaml
flutter:
  assets:
    - assets/images/dog.png
```

工作原理：
- Flutter 加载这一张 3x 高分辨率图
- 在 2x 屏幕上自动缩小渲染，看起来一样清晰
- 在 3x 屏幕上原尺寸渲染，最佳画质

**缺点：**低密度设备也要加载这张大图，内存占用会比加载 2x 版本稍高一点点。

**方案 2（折中**）：2x 当基准 + 3x 作为变体

```
assets/images/
  dog.png        ← 你的 @2x 文件（去掉后缀）
  3.0x/dog.png   ← 你的 @3x 文件（去掉后缀）
```

工作原理：
- 2x 设备加载 `dog.png`（实际是你的 2x 文件）
- 3x 设备加载 `3.0x/dog.png`

**缺点：** Flutter 在概念上把 `dog.png` 当作 1x 看待。如果你不显式指定 `width/height`，在理论上的 1x 设备上图片会显示得偏大，但是 1x 设备现在基本很少见了。

**方案 3** 使用 SVG ，矢量图天然无关分辨率，一份文件吃所有屏幕：

```yaml
dependencies:
  flutter_svg: ^2.0.0
```

使用：
```dart
import 'package:flutter_svg/flutter_svg.dart';
SvgPicture.asset('assets/images/dog.svg', width: 100)
```



## 2.Image

📋 `Image` Widget 常用属性与方法表格:

| 属性                 | 类型               | 说明    | 底层机制（原理级）    | 常见误区 & 最佳实践     |
| ------------------ | ---------------- | ---------------- | --------------------- | ------------- |
| **image**  | `ImageProvider?` | 用于加载图片的源（例如：`AssetImage`、`NetworkImage`、`FileImage`）  | `ImageProvider` 会根据不同的类型调用不同的解码器（如从磁盘、内存、网络等）  | 使用 `AssetImage` 时，确保图片资源已在 `pubspec.yaml` 中声明 |
| **height**/**width** | `double?` | 图片的宽高（如果设置，会根据按比例缩放） | 控制渲染时的尺寸，影响布局时的宽高计算  | 不建议使用硬编码的宽高，最好使用自适应布局 |
| **fit**            | `BoxFit`         | 控制图片的填充模式，如 `.cover`, `.contain`, `.fill` | 影响图片的缩放行为，决定如何适配父容器大小  | `.cover` 会裁剪图片，`.contain` 保证完整显示  |
| **alignment**      | `Alignment`  | 图片的对齐方式，默认为 `.center` | 控制图片在容器中的位置，影响布局时的对齐  | 默认情况下，`alignment` 是中对齐，设置时注意容器大小变化 |
| **repeat**   | `ImageRepeat` | 是否重复显示图片，如果设置为 `.repeat`，则会平铺显示图片  | 适用于小图片做为背景图  | 常用于 `BoxDecoration` 中作为背景  |
| **color**  | `Color?` | 为图片叠加颜色（常用于滤镜效果） | 通过 `ColorFilter` 叠加到图片上，影响其渲染效果 | `color` 和 `colorBlendMode` 一起使用可以创造更复杂的视觉效果 |
| **colorBlendMode** | `BlendMode?` | 颜色混合模式，用于叠加 `color` 属性 | 配合 `color` 使用，调整颜色叠加的方式（如：`BlendMode.colorBurn`） | 用于视觉特效，注意可能会影响性能 |
| **semanticLabel**  | `String?`| 用于屏幕阅读器的标签，增强可访问性  | 提供语义信息，以便语音读取时对用户进行说明  | 建议为所有图片提供 `semanticLabel`，提高无障碍体验   |
| **filterQuality**  | `FilterQuality`  | 控制图片的渲染质量，影响性能  | 提供低（`FilterQuality.low`）、中（`FilterQuality.medium`）、高（`FilterQuality.high`）质量选择 | 在性能敏感的场景下避免使用高质量渲染 |
| **isAntiAlias**    | `bool?` | 是否开启抗锯齿（对于一些矢量图效果明显）| 影响图片的边缘渲染效果，避免产生锯齿 | 启用抗锯齿会稍微影响性能，通常矢量图需要开启  |
| **cacheHeight**/**cacheWidth** | `int?` | 缓存图片的高度/宽度（默认与显示尺寸相同） | 控制图片在内存中的缓存大小，影响加载性能 | 建议根据实际情况调整，避免占用过多内存 |


**常见的用法：**

| 方法  | 说明    | 使用场景   |
| ------------- | -------------------- | --------------- |
| **Image.asset()**   | 从本地资源加载图片（需要在 `pubspec.yaml` 中声明资源） | 加载应用内的图片资源  |
| **Image.network()** | 从网络加载图片（支持缓存）| 加载网络图片 |
| **Image.file()**    | 从文件系统加载图片   | 加载本地文件系统中的图片 |
| **Image.memory()**  | 从内存中的字节数组加载图片  | 在内存中已经有图片字节数据时使用（例如：从数据库或缓存加载） |
| **image.resolve()** | 获取图片的 `ImageStream`，用于监听图片加载事件   | 用于高级用法，监听图片加载状态  |
| **image.width**     | 获取图片的宽度（需要先加载图片） | 读取图片加载后的原始尺寸  |
| **image.height**    | 获取图片的高度（需要先加载图片） | 读取图片加载后的原始尺寸  |


> 配置 `pubspec.yaml` 中的图片资源，确保图片文件在 `assets` 目录下，并且在 `pubspec.yaml` 中声明。具体查看`Flutter学习` -> `初识Flutter项目`

**代码示例**

```dart
// ✅ 正确用法：控制解码尺寸，减少内存占用
Image.network(
  'https://example.com/large-image.jpg',
  width: 100,  // 显示尺寸
  height: 100,
  cacheWidth: 200,  // 解码尺寸（2倍屏优化）
  cacheHeight: 200,
  fit: BoxFit.cover,
  filterQuality: FilterQuality.low, // 低过滤质量，性能优先
)

// ❌ 避免：加载大图无尺寸限制
Image.network(
  'https://example.com/4000x4000-image.jpg', // 16MB 原始图片
  // 没有 cacheWidth/cacheHeight，会解码完整尺寸
)

// ✅ 使用 FadeInImage 优化用户体验
FadeInImage(
  placeholder: MemoryImage(kTransparentImage), // 透明占位
  image: NetworkImage('https://example.com/image.jpg'),
  width: 200,
  height: 200,
  fadeInDuration: const Duration(milliseconds: 300),
  fadeOutDuration: const Duration(milliseconds: 200),
)

// ✅ 图片列表优化：使用 RepaintBoundary
ListView.builder(
  itemCount: 100,
  itemBuilder: (context, index) {
    return RepaintBoundary(
      child: Image.network(
        'https://example.com/image$index.jpg',
        cacheWidth: (MediaQuery.of(context).size.width * 
                    WidgetsBinding.instance.window.devicePixelRatio).ceil(),
        loadingBuilder: (context, child, loadingProgress) {
          if (loadingProgress == null) return child;
          return Shimmer.fromColors( // 骨架屏效果
            baseColor: Colors.grey[300]!,
            highlightColor: Colors.grey[100]!,
            child: Container(color: Colors.white),
          );
        },
      ),
    );
  },
)
```

**异步加载与占位符**
```dart
Image.network(
  'https://example.com/image.jpg',
  loadingBuilder: (context, child, loadingProgress) {
    if (loadingProgress == null) {
      return child; // 图片加载完成
    } else {
      return Center(
        child: CircularProgressIndicator(
          value: loadingProgress.expectedTotalBytes != null
              ? loadingProgress.cumulativeBytesLoaded /
                  (loadingProgress.expectedTotalBytes ?? 1)
              : null,
        ),
      );
    }
  },
)
```

## 3.TextField

`TextField` 常用属性:

| 属性  | 类型 | 说明  | 底层机制（原理级） | 常见误区 & 最佳实践 |
| ----------------- | ----------------- | ----------------- | ------------------- | ------------ |
| **controller**  | `TextEditingController?`  | 用于控制 `TextField` 的文本内容。可通过它获取和设置文本 | `TextEditingController` 会监听文本的变化，并通过 `TextInput` 与底层平台进行交互 | 在使用 `TextEditingController` 时，记得在 `dispose()` 中手动释放  |
| **focusNode** | `FocusNode?`  | 用于管理 `TextField` 的焦点状态（是否获得输入焦点） | `FocusNode` 会与平台进行交互来处理焦点变化，触发键盘弹出或收回等操作 | 若有多个 `TextField`，使用 `FocusNode` 来管理焦点切换  |
| **keyboardType**  | `TextInputType?`  | 定义键盘的类型，如：`.text`, `.number` | 根据不同的 `keyboardType`，底层会调用平台的输入法来显示相应的键盘类型 | 例如：设置 `.number` 时会弹出数字键盘 |
| **obscureText** | `bool`  | 是否隐藏文本（常用于密码输入框）  | 会触发底层输入法的显示模式，以隐藏文本的明文显示 | 常用于密码字段，确保隐私保护 |
| **style** | `TextStyle?`  | 用于设置输入文本的样式，包括字体、大小、颜色等  | 通过 `TextPainter` 来渲染文本样式，影响文本的绘制 | 提供合适的样式和布局 |
| **decoration**  | `InputDecoration?`  | 输入框的装饰，如：边框、提示文本、图标等 | `InputDecoration` 是一个高度自定义的 UI 元素，内部分为多个小部件来构建界面 | 用于定制非常复杂的输入框样式  |
| **onChanged** | `ValueChanged<String>?` | 当文本变化时回调，接收当前文本值 | 每次文本输入变化时会触发回调函数 | 适用于实时获取文本变化并进行处理 |
| **onSubmitted** | `ValueChanged<String>?` | 当用户提交（通常是按下回车键）时触发的回调  | 监听提交事件，通常用于提交表单或触发搜索功能 | 用于表单的提交逻辑 |
| **enabled** | `bool?` | 控制 `TextField` 是否可用（禁用时不可编辑） | 当设置为 `false` 时，内部组件会被禁用并且无法交互  | 在禁用状态下，TextField 将无法接收输入 |
| **maxLength** | `int?`  | 设置最大输入长度  | 会限制用户输入的字符数，当输入达到 `maxLength` 后不能继续输入  | `maxLength` 可以结合 `inputFormatters` 限制输入字符的类型 |
| **inputFormatters** | `List<TextInputFormatter>?` | 输入格式化器，用于限制输入的格式（例如限制为数字或字母） | 通过 `TextInputFormatter` 可以对输入进行校验或转换 | 常用来限制输入字符的类型（如只允许输入数字） |
| **autofocus** | `bool`  | 设置 `TextField` 是否自动获得焦点  | 如果设置为 `true`，则该 `TextField` 会在页面加载时自动获得焦点并弹出键盘 | 如果有多个 `TextField`，避免设置多个 `autofocus`，否则会导致意外行为 |
| **maxLines**  | `int?`  | 设置 `TextField` 的最大行数 | 控制文本框的最大高度，如果文本超过最大行数，则会滚动显示 | 适用于多行输入框（如备注、评论框等） |
| **minLines**  | `int?`  | 设置 `TextField` 的最小行数 | 当文本较少时，保证至少显示指定行数  | 与 `maxLines` 配合使用，调整多行文本框的大小 |
| **textAlign** | `TextAlign?` | 文本对齐方式，如：`.left`, `.center`, `.right` | 控制文本在 `TextField` 中的水平对齐 |  |
| **cursorWidth** | `double?` | 光标宽度 | 控制光标在 `TextField` 中的宽度 |  |
| **cursorHeight** | `double?` | 光标高度 | 控制光标在 `TextField` 中的高度 |  |
| **cursorRadius** | `Radius?` | 光标圆角半径 | 控制光标在 `TextField` 中的圆角半径 |  |


> 使用 `TextField` 时，需要使用 `StatefulWidget` 来管理文本输入状态。这是因为 `TextField` 是一个有状态的小部件，它需要维护文本输入的状态，如当前输入的文本内容、光标位置等。
