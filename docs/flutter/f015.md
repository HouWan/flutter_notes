## 1.PageView

`PageView` 是 Flutter 中专门用于构建分页滑动视图（如引导页、图片 Banner、Tab 切换页、TikTok 式短视频上下滑）的核心 Widget。从底层架构来看，`PageView` 是对 `Scrollable` + `Viewport` + `SliverFillViewport` + `PageScrollPhysics` 的高级封装。

在实际工程开发中，对 `PageView` 的操作通常由 `PageView` 本身（布局与手势） 与 `PageController`（控制与状态） 配合完成。

### 1.1 常用构造函数 (Constructors)

| 构造函数 | 对应 Delegate | 源码/原理级作用说明 |
| --- | --- | --- |
| **`PageView(...)`** | `SliverChildListDelegate` | **全量加载模式**。在 `build` 阶段一次性实例化所有 `children` Widget。**仅适用于已知页数极少（如 3-5 页引导页）且无重度内存压力的场景**。 |
| **`PageView.builder(...)`** | `SliverChildBuilderDelegate` | **按需懒加载模式**。Viewport 在 Layout 阶段仅对当前页及预渲染区域（`cacheExtent`）的 `index` 调起 `itemBuilder`。大数据量或无限轮播图**必须**使用此构造函数。 |
| **`PageView.custom(...)`** | 自定义 `SliverChildDelegate` | **高级 Delegate 模式**。可自定义 Index 查找与映射规则（如配合 `Key` 实现复杂的页面重排与 Element 树复用）。 |

### 1.2 PageView 核心属性表

| 属性名称 | 类型 & 默认值 | 源码/原理级作用说明 |
| --- | --- | --- |
| **`controller`** | `PageController` 默认值 `_defaultPageController` | **核心控制器**。持有当前的页面索引、视口比例（`viewportFraction`）以及底层的 `ScrollPosition`。 |
| **`scrollDirection`** | `Axis` 默认值 `Axis.horizontal` | 滚动主轴方向。`Axis.horizontal` 为左右翻页，`Axis.vertical` 为上下翻页（如短视频切换）。 |
| **`reverse`** | `bool` 默认值 `false` | 是否反向布局。为 `true` 时，`index = 0` 位于最右侧/最底部，且滑动方向颠倒。 |
| **`physics`** | `ScrollPhysics?` 默认值 `null` | 物理滚动反馈。默认组合 **`PageScrollPhysics`**，强制让滚动手势在释放时按页面边界对齐（Snapping）。 |
| **`pageSnapping`** | `bool` 默认值 `true` | 是否开启页面吸附。若设为 `false`，`PageView` 会退化为普通的线性列表，失去了“一页一页停顿”的分页特性。 |
| **`onPageChanged`** | `ValueChanged<int>?` 默认值 `null` | **页码变更回调**。当滚动手势结算（Ballistic Simulation）结束且动画停留在新的页面索引时触发。 |
| **`allowImplicitScrolling`** | `bool` 默认值 `false` | **隐式预渲染开关**。为 `true` 时，底层 `SliverFillViewport` 会强制为当前页的前后相邻页创建 Element/RenderObject，利于无障碍读屏（VoiceOver）与提前加载。 |
| **`padEnds`** | `bool` 默认值 `true` | **边缘填充开关**。当 `PageController.viewportFraction < 1.0` 时，是否在列表首尾自动添加 Padding，使得第 0 页和最后一页能居中显示。 |
| **`clipBehavior`** | `Clip` 默认值 `Clip.hardEdge` | 裁剪策略。当子页面超出 Viewport 边界时的 Canvas 裁剪行为。 |
| **`dragStartBehavior`** | `DragStartBehavior` 默认值 `start` | 手势识别起点。`start` 表示从手势满足判定条件时突变开始，`down` 表示从按下瞬间平滑追踪。 |

### 1.3 PageController 核心属性与控制方法表

`PageView` 的大部分编程式控制（如平滑跳转、跳转指定页、获取当前精确浮点页码）全由 `PageController` 驱动。

| 属性 / 方法 | 类型 / 返回值 | 源码/原理级作用说明 |
| --- | --- | --- |
| **`initialPage`** *(属性)* | `int` | **初始页码**（默认 `0`）。在底层 `ScrollPosition` 第一次附加（Attach）时确立初始的 `scrollOffset`。 |
| **`viewportFraction`** *(属性)* | `double` | **视口占用比例**（默认 `1.0`）。取值 `0.0 ~ 1.0`。若设为 `0.85`，则当前页占据视口的 85%，两侧可露出上一页和下一页的边角（常用于卡片式 Banner 效果）。 |
| **`keepPage`** *(属性)* | `bool` | **状态保持**（默认 `true`）。当 `PageView` 重新构建时，是否通过 `PageStorage` 记住并恢复之前的滚动偏移量。 |
| **`page`** *(Getter)* | `double?` | **当前精确页码**。返回的是**浮点数**（例如滑动到第 1 页和第 2 页中间时返回 `1.5`）。必须在 `hasClients == true` 时访问。 |
| **`animateToPage(...)`** | `Future<void>` | **带动画跳转页码**。需传入 `page`、`duration`（动画时长）与 `curve`（动画曲线）。底层使用 `ScrollPosition.animateTo`。 |
| **`jumpToPage(...)`** | `void` | **无动画无缝跳转**。直接修改 `ScrollPosition.pixels`。常用于无限轮播图首尾 Index 的瞬间重置。 |
| **`nextPage(...)`** | `Future<void>` | **跳转下一页**。封装了 `animateToPage(page + 1)`。 |
| **`previousPage(...)`** | `Future<void>` | **跳转上一页**。封装了 `animateToPage(page - 1)`。 |

### 1.4 注意点

1.`PageView` 的子 Widget 为什么能刚好塞满一屏，而不需要开发者手动指定 `width/height`？

在 Render Tree 层级，`PageView` 构建了 **`RenderSliverFillViewport`**。在 Layout 阶段：

1.1. `RenderViewport` 得到屏幕卡槽尺寸 `viewportDimension`（比如高 `844`pt，宽 `390`pt）。
1.2. `RenderSliverFillViewport` 在对每一个子节点进行 `layout()` 时，会下发强制的**紧约束（Tight Constraints）**：
  - `itemSize` = `viewportDimension` x `viewportFraction`

1.3. 因此，无论你在 `PageView` 里面放什么组件，它的尺寸都会被强行拉伸/压缩为 `PageController.viewportFraction` 所指定的精确定量。


2.页面吸附物理原理

普通列表滑动松开手指后，会根据惯性减速直到自然停止；而 `PageView` 必须停在页面的整数倍位置。

### 2 代码示例

**Banner 轮播图示例***

```dart
class _MainPageState extends State<MainPage> {
  final int bannerCount = 10; // 总共多少个 banner
  int _currentIndex = 0; // 当前索引
  final PageController _controller = PageController();  // 滚动控制
  late List<Color> bgColors = List.generate(bannerCount, (_) => getRandomColor());  // 背景色

  @override
  void dispose() {
    _controller.dispose();  // 不能忘记 dispose
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Container(
      width: double.infinity,
      height: 220,
      color: Colors.blue,
      child: Stack(
        children: [
          PageView.builder(
            controller: _controller,
            itemCount: bannerCount,
            itemBuilder: (BuildContext c, int i) {
              return Container(
                color: bgColors[i],
                alignment: .center,
                child: Text("第 $i 个", style: TextStyle(color: Colors.white)),
              );
            },
            onPageChanged: (v) {
              setState(() {
                _currentIndex = v;
              });
            },
          ),
          Positioned(
            bottom: 16,
            right: 0,
            left: 0,
            child: Row(
              mainAxisAlignment: .center,
              spacing: 10,
              children: List.generate(bannerCount, (int i) {
                return GestureDetector(
                  onTap: () {
                    _controller.animateToPage(i, duration: Duration(seconds: 1), curve: Curves.easeIn);
                    // 也可以在这里 更新 setState() { _currentIndex = v }
                  },
                  child: Container(
                    width: 12,
                    height: 12,
                    decoration: BoxDecoration(
                      color: _currentIndex == i ? Colors.blue : Colors.white,
                      borderRadius: BorderRadius.circular(6),
                    ),
                  ),
                );
              }),
            ),
          ),
        ],
      ),
    );
  }

  Color getRandomColor() {
    final r = Random();
    return Color.fromARGB(255, r.nextInt(256), r.nextInt(256), r.nextInt(256));
  }
}
```
