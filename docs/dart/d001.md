## 2.变量和常量

```dart
// 1.变量，使用 var 声明，一旦确定类型后，后续类型不可变化
var age = 18;
age = 20;

// 2.使用 const 声明常量，常量不可变
const pi = 3.1415;
print(pi);

var tmp = 18;
const tmpConst = tmp * 2;  // 报错，const 表达式里面不能有变量

// 注意，在 Swift 语言中，let 声明的常量中，是可以包含var的表达式的。

// 因为 Dart 的 const 是代码编译中被确定的，不允许表达式中有变量存在
// 而 Swift 是在运行中，第一次分配内存确定的。

// 3.使用 final 声明常量，跟 Swift 的 let 一样，在运行时确定值后，将不能被修改
final time = DateTime.now();
```

## 4.数字和布尔

三种类型：
- `int`: 整型数字
- `num`: 可整型可小数
- `double`: 小数

```dart
int age = 18;
double pi = 3.1415;

num myVal = 18;  // 整数
myVal = 20.15;  // 也可以赋值为小数

age = pi.toInt();  // 有转换类型方法 int to double
pi = age.toDouble();  // double to int

// double类型有原生的 ceil 和 floor 方法
pi.ceil();
pi.ceilToDouble();
pi.floor();
pi.floorToDouble()

// 布尔类型
bool isFinish = true;  // 或者 false
```

## 5.列表类型-List

基本的操作：
```dart
List data = [1, 2, 3, 4, "hello"];

print(data.length);  // 获取 长度 length
print(data.first);  // 第一个元素
print(data.last);  // 最后一个元素
print(data.lastOrNull);  // 最后一个 or null
print(data.isEmpty);  // 是否为空，isNotEmpty

data.add("world");  // 尾部增加
data.addAll([]);  // 尾部增加一个列表
data.removeAt(0);  // 删除指定索引的元素。小心越界。
data.removeLast();  // 删除最后一个元素
data.removeRange(0, 3);  // 删除索引 0 到 3。小心越界。
```

常用的方法：
```dart
List data = [1, 2, 3, 4, "hello"];

// For-Each，参数是 函数名
data.forEach(print);

// For-Each，匿名函数? 闭包？  (args...) {}
data.forEach((item) {
    print(item);
});

data = [89, 23, 56, 2, 5, 42, 28];

// 是否都满足条件 every(fn)
final res = data.every((item) {
    return item > 1;
});
print(res);

// 筛选出满足条件的数据  where(fn)  返回迭代器
// 迭代器 可以 for-in  for-each   toList
final res = data.where((item) { return item > 20; });

// 普通for循环 遍历列表  (使用 int 或者 var 都可以)
for (int i = 0; i < data.length; i++) {
    print(data[i]);
}
```

## 7.动态类型-dynamic

`dynamic`允许变量在运行时自由改变类型。`dynamic`可以直接调用属性和方法，而不需要进行类型转换。但是如果调用的属性或方法不存在，会在运行时抛出异常。

> 和`var`最大的区别是: `var`是有类型检查的。

## 8.空安全机制

和`Swift`的空安全机制类似, `Dart`也有空安全机制，如下：

- `?` 声明可空变量
- `?.` 可选调用运算符，当变量为空时，不会抛出异常，返回`null`
- `!.` 非空断言，当变量为空时，会抛出异常
- `??` 空合并运算符，当变量为空时，返回默认值

```dart
String? text = null;
print(text?.length ?? 0);

String content = text ?? "我是默认值";
```

### 9.2 类注释
```dart
/// 表示一个用户实体
///
/// 该类包含用户的基本信息，如姓名、年龄和邮箱地址
/// 使用 [User.fromJson] 构造函数可以从JSON数据创建用户对象
/// 使用 [toJson] 方法可以将用户对象转换为JSON格式
///
/// 示例：
/// ```dart
/// var user = User('张三', 25, 'zhangsan@example.com');
/// print(user.name); // 输出: 张三
/// ```
class User {
  /// 用户的姓名
  ///
  /// 不能为空，最大长度为50个字符
  final String name;

  /// 用户的年龄
  ///
  /// 必须大于0且小于150
  final int age;

  /// 用户的邮箱地址
  ///
  /// 必须符合邮箱格式，可以为空
  final String? email;

  /// 创建一个用户实例
  ///
  /// [name] 用户的姓名，不能为空
  /// [age] 用户的年龄，必须大于0
  /// [email] 用户的邮箱地址，可选参数
  User(this.name, this.age, [this.email]);

  /// 从JSON数据创建用户实例
  ///
  /// [json] 包含用户数据的Map对象
  /// 期望的JSON格式：
  /// ```json
  /// {
  ///   "name": "张三",
  ///   "age": 25,
  ///   "email": "zhangsan@example.com"
  /// }
  /// ```
  User.fromJson(Map<String, dynamic> json)
      : name = json['name'],
        age = json['age'],
        email = json['email'];

  /// 将用户对象转换为JSON格式
  ///
  /// 返回包含用户数据的Map对象
  Map<String, dynamic> toJson() {
    return {
      'name': name,
      'age': age,
      'email': email,
    };
  }
}
```   

### 9.3 属性注释
```dart
class Product {
  /// 产品名称
  ///
  /// 此属性为只读，创建后不能修改
  /// 使用 [Product] 构造函数设置初始值
  final String name;

  /// 产品价格，单位为元
  ///
  /// 必须大于0，可以使用 [applyDiscount] 方法应用折扣
  double price;

  /// 库存数量
  ///
  /// 当库存为0时，产品标记为缺货
  /// 使用 [restock] 方法补充库存
  int _stockCount;

  /// 创建一个产品实例
  ///
  /// [name] 产品名称，不能为空
  /// [price] 产品价格，必须大于0
  /// [stockCount] 初始库存数量，默认为0
  Product(this.name, this.price, [this._stockCount = 0]);

  /// 应用折扣到产品价格
  ///
  /// [discountPercentage] 折扣百分比，范围0-100
  /// 示例：25表示25%的折扣
  ///
  /// 抛出 [ArgumentError] 当折扣百分比不在0-100范围内
  void applyDiscount(double discountPercentage) {
    if (discountPercentage < 0 || discountPercentage > 100) {
      throw ArgumentError('折扣百分比必须在0-100之间');
    }
    price = price * (1 - discountPercentage / 100);
  }
}
```
