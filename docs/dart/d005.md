
## 1.事件循环

Dart是单线程语言，事件循环是 Dart 运行时的一个重要机制，用于处理异步操作。事件循环的基本原理如下：

- 1. 事件循环是一个无限循环，用于监听事件队列中的事件。
- 2. 事件队列是一个先进先出（FIFO）的队列，用于存储待处理的事件。
- 3. 事件循环会不断地从事件队列中取出事件，并执行对应的回调函数。
- 4. 如果事件队列中没有事件，事件循环会阻塞在那里，等待新的事件到来。
- 5. 事件循环流程是 执行同步代码 -> 执行微任务队列 -> 执行事件队列
- 6. 微任务队列: `Future.microtask()` 队列，用于存储微任务。微任务的优先级高于事件队列中的任务。
- 7. 事件队列: 用于`Future`、`Future.delayed()`、用户交互事件、定时器事件、网络请求事件等。


| 概念 | 作用 | 类比 |
| --- | --- | --- |
| `Future` | 表示一个**单次**异步操作的结果 | 类似于 `JavaScript` 的 `Promise` |
| `Stream` | 表示一个**连续**的异步事件序列 | 类似于 `RxJS` 的 `Observable` |
| `async`/`await` | 让异步代码看起来像同步代码 | 语法糖，简化异步编程 |
| `Isolate` | Dart 的并发模型（类似线程） | 类似于 `Web Worker` |



## 2.Future

### 2.1 基本概念
`Future`表示一个**单次**异步操作的最终结果，有三种状态：
- `uncompleted`：等待状态，异步操作还没有完成，也没有出错。
- `completed`：成功结果，异步操作成功完成，有一个结果值。
- `error`：失败结果，异步操作出错，有一个错误对象。

所以，三种状态对应了下面几个基本代码块：
- `uncompleted`：等待状态，对应 `Future(() {})` 即：创建一个 Future 对象，默认就是等待状态。
- `completed`：成功结果，对应 `then(() {})` 方法的回调函数。
- `error`：失败结果，对应 `catchError()` 方法的回调函数。(比如使用 `throw Exception()` 抛出异常)
- `whenComplete`：无论异步操作是否成功，都会执行的回调函数。


```dart
// 1. 定义一个 Future 对象，默认就是等待状态
var future = Future(() {
  // return "hello world";
  // 没有抛出异常，那就是成功结果，下面代码测试抛出异常
  throw Exception("hello error");
});

// 2. 调用 then 方法，添加成功回调函数
future.then((value) {
  print(value);
});

// 3. 调用 catchError 方法，添加失败回调函数
future.catchError((error) {
  print(error);
});
```


### 2.2 Future链式调用

链式调用示例：

```dart
// 链式调用示例一：
Future(() {
      return "hello world";
      // 没有抛出异常，那就是成功结果，下面代码测试抛出异常
      // throw Exception("hello error");
    })
    .then((value) {
      print(value);
    })
    .catchError((error) {
      print(error);
    })
    .whenComplete(() {
      print("完成");
    });

// 链式调用示例二：
Future(() {
      return "hello world";
    })
    .then((value) {
      return value + " 100";
    })
    .then((value) {
      return value + " 200";
    })
    .then((value) {
      print(value);
    })
    .catchError((error) {
      print(error);
    })
    .whenComplete(() {
      print("完成");
    });
```

### 2.3 Future-async/await

`async`/`await` 是 Dart 中用于处理异步操作的语法糖，它可以让异步代码看起来像同步代码，使代码更加易读和维护。

- `async` 关键字用于标记一个函数是异步的，它会返回一个 `Future` 对象。
- `await` 关键字用于等待一个异步操作完成，它只能在异步函数中使用。
- `await` 后面跟着一个 `Future` 对象，它会暂停当前异步函数的执行，等待 `Future` 对象完成，然后返回结果才会继续执行后续的代码。
- 如果 `Future` 对象抛出异常，`await` 会捕获异常，使异步函数抛出异常。
- `await` 可以用在 `try` 语句中，捕获异步操作抛出的异常。
- `await` 可以用在 `for` 循环中，等待多个异步操作完成。

基础语法：
```dart
// 1.异步函数
函数名() async {
  try {
    // 异步操作
    await Future.delayed(Duration(seconds: 1));
    // 异步操作完成后，继续执行后续代码
    print("异步操作完成");
  } catch (error) {
    // 捕获异步操作抛出的异常
    print(error);
  }
}

// 2.使用 await 等待异步操作完成
String result = await Future(() {
  return "hello world";
});
print(result);
```


代码示例：
```dart
// 异步函数，没有返回值
void test() async {
  try {
    // 异步操作
    await Future.delayed(Duration(seconds: 2));
    // 异步操作完成后，继续执行后续代码
    print("异步操作完成");
  } catch (error) {
    // 捕获异步操作抛出的异常
    print(error);
  }
}

// 异步函数，有返回值
Future<String> testReturn() async {
  try {
    // 异步操作
    await Future.delayed(Duration(seconds: 2));
    // 异步操作完成后，继续执行后续代码, 返回成功结果
    return "异步操作成功";  // 会自动包装成 Future 对象
  } catch (error) {
    // 捕获异步操作抛出的异常
    throw Exception("异步操作出错");   // 会自动包装成 Future 对象
  }
}

// 调用示例：
// 调用异步函数
test();

// 调用异步函数返回值
testReturn()
    .then((value) {
      print(value);
    })
    .catchError((error) {
      print(error);
    });
```
