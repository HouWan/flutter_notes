
## 1.基本函数定义

基本函数定义如下，没有返回值使用`void`：
```dart
// 基本函数定义

// 返回值 函数名(参数类型 参数名) {
//     函数体
//     return 返回值;
// }

int add(int a, int b) {
    return a + b;
}

// 当省去返回值类型时，则默认是 dynamic 类型（不推荐）
add(int a, int b) {
  return a + b;
}
```

## 2.可选参数

**可选位置参数**

`可选位置参数`必须位于参数列表的最后面，采用中括号`[]`包裹。如下：
```dart
// 定义一个函数，参数是一个函数， 有默认值
int add(int a, int b, [int c = 0]) {
    return a + b + c;
}

// 定义一个函数，参数是一个函数， 可选参数 可以为空
int add(int a, int b, [int? c, int? d]) {
  return a + b + (c ?? 0) + (d ?? 0);
}
```

**可选命名参数**

`可选命名参数`采用大括号`{}`包裹，参数之间用逗号`,`隔开。如下：

```dart
// 定义一个函数，参数是一个函数， 可选参数 可以为空
void sayHello(String name, {String? msg, int? age}) {
  print('hello world $name $msg $age');
}

// 也可以有默认值
void sayHello(String name, {String? msg = "love", int? age}) {
  print('hello world $name $msg $age');
}

// 调用时，可选参数可以不传递
sayHello("name");
sayHello("name", msg: "hello", age: 18);
sayHello("name", age: 18);
```

**总结可选位置参数和可选命名参数的区别：**

| 区别 | 可选位置参数 | 可选命名参数 |
|---|---|---|
| 定义 | 中括号`[]`包裹 | 大括号`{}`包裹 |
| 是否必须传递 | 否 | 否 |
| 是否可以有默认值 | 是 | 是 |
| 调用时是否需要参数名 | 否 | 是 |
| 调用方式 | 按位置传递 | 按命名传递 |
| 参数顺序 | 必须按声明顺序 | 顺序可以任意 |
| 可读性 | 较低，需要记住位置 | 较高，参数名清晰 |
| 适用场景 | 参数有逻辑顺序时 | 参数较多或意义重要时 |

二者代码结合：

```dart
// 位置参数 + 命名参数混合
void complexFunction(
  String required1, 
  int required2, 
  [String? optionalPositional], 
  {String named1 = "default1", int named2 = 100}
) {
  print('$required1, $required2, $optionalPositional, $named1, $named2');
}

// 调用
complexFunction("hello", 1);
complexFunction("hello", 1, "positional");
complexFunction("hello", 1, named1: "custom");
complexFunction("hello", 1, "positional", named2: 200);
```

> 所以更推荐使用可选命名参数`{类型 参数名 = 默认值, 类型 参数名2 = 默认值2, ...}`。


## 3.匿名函数

匿名函数是没有函数名的函数，并且可以赋值给一个变量进行调用，如下：
```dart
// 使用 Function 类型定义一个匿名函数
Function addFn = (int a, int b) {
  return a + b;
};

// 调用匿名函数
int res = addFn(2, 3);
print(res);

Function pFn = () {
  print("hello");
};

// 将匿名函数作为参数传递
// 定义一个函数，参数是一个函数， 有默认值
void addTest(Function callback) {
  callback();
}

addTest(pFn); // 调用 addTest 函数，传递 pFn 函数作为参数
```

## 4.箭头函数
当函数体只有一行代码时，可以使用箭头函数进行简写，如下：
- 箭头函数没有`return`关键字，直接返回表达式的值。

```dart
// 定义一个函数，参数是一个函数
Function addFn = (int a, int b) => a + b;

// 调用匿名函数
int res = addFn(2, 3);
print(res);
```


函数可以作为参数传递，如下：
```dart
// 定义一个简单的函数，用于加法
int add(int a, int b) => a + b;

// 定义一个函数，参数是一个函数
void process(int Function(int, int) fn) {
  int res = fn(2, 3);
  print(res);
}

// 调用时，传递一个函数作为参数
process(add);
```
