## 1.类的定义
跟其他语言一样，dart 也有类的定义，类的定义包括类名、属性、方法、构造函数等。

```dart
// 😄定义一个 学生类
class Student1 {
  String name; // 如果不初始化，则必须在构造函数中初始化
  int age;

  // 构造函数 （简写的方式）推荐的写法
  // Student1(this.name, this.age);

  // 构造函数 （使用初始化列表的方式）
  // Student1(String name, int age):
  //   this.name = name,
  //   this.age = age;

  // 🌹构造函数 （简洁的写法，可以在构造函数中加上一些逻辑）
  Student1(this.name, this.age) {
    print("哈哈哈，我被调用了");
  }

  void printInfo() {
    print("姓名：$name，年龄：$age");
  }
}

// 😄定义类 Student2
class Student2 {
  String name = ""; // 有默认值，则可以不强制用在构造函数中初始化
  int age = 0;
}

// 😭定义类 Student3
class Student3 {
  String name = ""; // 有默认值，则可以不强制用在构造函数中初始化
  int age = 0;

  // 构造函数 （使用命名参数的方式）🐱
  Student3({String? name, int? age}) {
    this.age = age ?? 0; // 如果 age 有值，就赋值给 this.age，否则就赋值为 0
    if (name != null) {
      // 如果 name 有值，就赋值给 this.name，否则就不处理
      this.name = name;
    }
  }
}
```


调用和实例化类的对象，需要使用构造函数。

```dart
Student1 stu1 = Student1("张三", 18);
stu1.printInfo();

var stu2 = Student2();  // 也可以直接使用 var 或者 final
stu2.name = "李四";
stu2.age = 20;
stu2.printInfo();
```

## 2.命名构造函数

语法是 `类名.构造函数名(参数列表)`

```dart
class Student1 {
  String name; // 如果不初始化，则必须在构造函数中初始化
  int age;

  /// 默认构造函数
  Student1(this.name, this.age);

  /// 命名构造函数
  /// 语法是 类名.构造函数名(参数列表)，可以和 默认构造函数 同时存在
  Student1.create(this.name, this.age);

  // 注意，上面是 语法糖 的写法，等价于下面的代码
  // Student1.create2(String name, int age): this.name = name, this.age = age;
}

// 使用命名构造函数创建对象
var stu1 = Student1.create("张三", 18);
```

## 3.公有&私有的属性(方法)
在 Dart 中，私有属性以`_`下划线开头，例如`_name`，其余均为公有属性。

```dart
// 公有属性 和 私有属性 代码示例：
class Person {
  String name = "";  // 公有属性
  int _age = 0;  // 私有属性

  /// 公有方法
  void printInfo() {
    print("姓名：$name，年龄：$_age");
  }

  /// 私有方法
  void _printAge() {
    print("年龄：$_age");
  }
}
```

> 注意：类的属性 和 方法只要是`_`开头的，都是私有属性和方法，只能在类的内部使用。


## 4.类的继承

使用关键字`extends`来实现类的继承；使用`@override`注解来重写父类的方法；使用`super`关键字来调用父类的方法。

- 注意：子类不会继承父类构造方法，子类必须通过`super`来调用父类构造方法以确保父类初始化。


```dart
class Person {
  String name = ""; // 公有属性
  int _age = 0; // 私有属性

  /// 默认构造函数
  Person(this.name, this._age);

  /// 公有方法
  void printInfo() {
    print("姓名：$name，年龄：$_age");
  }

  /// 私有方法
  void _printAge() {
    print("年龄：$_age");
  }
}

// 子类可以继承父类的属性和方法，也可以重写父类的方法
class Student extends Person {
  /// 子类调用父类的构造函数，来确保父类的初始化
  Student(String name, int age) : super(name, age);

  /// 子类可以重写父类的方法
  @override
  void printInfo() {
    print("我是子类 Student，姓名：$name，年龄：$_age");
  }
}
```


## 5.抽象类和接口

使用关键字`abstract`来定义抽象类，抽象类不能被实例化，只能被继承(`extends`)或实现(`implements`)。

```dart
// 定义一个抽象类
abstract class Animal {
  String name = "动物";  // 具体字段

  // 抽象方法，没有方法体
  void eat();

  // 普通方法，有方法体
  void sleep() {
    print("动物在睡觉");
  }
}

// 实现抽象类
class Dog implements Animal {
  @override
  String name = "狗";  // 必须重新声明字段

  // 必须实现抽象方法
  @override
  void eat() {
    print("狗在吃");
  }

  // 也必须实现普通方法
  @override
  void sleep() {
    print("狗在睡觉");
  }
}

// 继承抽象类
class Cat extends Animal {
  @override
  String name = "猫";  // 可以重新声明字段，也可以不重新声明
  
  // 必须实现抽象方法
  @override
  void eat() {
    print("猫在吃");
  }
}
```

Dart 中 `extends` 与 `implements` 的区别表格：

| 区别 | `extends`继承 | `implements`实现 |
| --- | --- | --- |
| 实现方式 | 子类继承父类 | 子类实现接口 |
| 方法实现 | 必须实现父类的**所有抽象方法和普通方法** | 必须实现接口的**所有抽象方法**，可选重写普通方法 |
| 字段/属性 | 可以重新声明字段，也可以不重新声明 | **必须重新声明字段** |
| 继承关系 | 是"是一个"的关系 <br /> (`Dog` 是 `Animal`) | 是"能够"的关系<br /> (`Cat` 能够 像 `Animal` 一样行为) |
| 多继承 | 不支持 | 子类实现多个接口 |


实际开发中的经验法则：
```dart
// 大多数情况下使用 extends
class Button extends StatelessWidget {}  // Flutter 中常见

// 需要多继承时使用 implements
class MyClass implements Interface1, Interface2, Interface3 {}

// 既想复用代码又想实现接口时
class AdvancedClass extends BaseClass implements AdditionalInterface {}
```

## 6.混入Mixin
在 Dart 中，你可以使用 `mixin` 关键字来定义一个混入类，然后使用 `with` 关键字将混入类添加到一个类中。

- 一个类支持`with`多个`mixin`，调用优先级遵循后来居上原则，则：**后混入的会覆盖先混入的同名方法**。

```dart
// 定义一个混入类
mixin Swimmable {
  void swim() {
    print("正在游泳");
  }
}

// 定义一个类，使用 with 关键字添加混入类
class Duck extends Animal with Swimmable {
  // 必须实现抽象方法
  @override
  void eat() {
    print("鸭子在吃");
  }
}

// 混入多个 mixin，使用 , 号分割，例如:
// class Duck extends Animal with Swimmable, Flyable {}

/// 创建一个 Duck 对象
var duck = Duck();
duck.eat(); // 输出：鸭子在吃
duck.swim(); // 输出：正在游泳
```


`mixin`在`Flutter`中的运用示例：

```dart
// 示例：AutomaticKeepAliveMixin 用于保持状态在页面切换时不被销毁
mixin AutomaticKeepAliveMixin<T extends StatefulWidget> on State<T> {
  @override
  bool get wantKeepAlive => true;
}

// <T extends StatefulWidget>
// 这是一个泛型约束: T 是一个类型参数，必须是 StatefulWidget 或其子类
// 这确保了 AutomaticKeepAliveMixin 只能被添加到 StatefulWidget 或其子类的 State 中
// 因为只有 StatefulWidget 才支持状态保持


// on State<T>
// on 关键字用于限制 Mixin 的使用范围: 这个 Mixin 只能被用于 State<T> 类或其子类
// 这不是继承关系，而是使用范围的约束

// 因为在 State 类中，已经有 wantKeepAlive 属性，并且默认是 false
// 所以这里需要将 wantKeepAlive 覆盖为 true，所以需要使用 @override 注解

// ⚠️根据我的实验，不加 @override 注解，也可以正确的覆盖 wantKeepAlive 属性
// 但是为了代码的可读性和维护性，建议始终使用 @override 注解

```
