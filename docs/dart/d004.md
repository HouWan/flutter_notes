
## 1.函数中的泛型
代码示例如下：
```dart
// 函数中的泛型 -- 定义一个函数，使用泛型参数 T
// <T> 就是定义一个泛型的语法
T getFirst<T>(List<T> list) {
  return list[0];
}

// 函数中的泛型 -- 定义一个函数，使用泛型参数 T
T getType<T>(T value) {
  return value;
}


// 调用 getType 函数，指定泛型参数为 String
//（其实可以省略，因为 Dart 可以根据参数类型推断出泛型参数）
var res = getType<String>("hello");
print(res);
```

## 2.类中的泛型
代码示例如下：
```dart
// 类中的泛型 -- 定义一个类，使用泛型参数 T
class Box<T> {
  // 泛型属性
  T value;

  // 构造函数
  Box(this.value);

  // 泛型方法
  void setValue(T value) {
    this.value = value;
  }

  T getValue() {
    return value;
  }
}

// 调用 Box 类，指定泛型参数为 String
var box = Box<String>();
box.setValue("hello");
print(box.getValue());
```
